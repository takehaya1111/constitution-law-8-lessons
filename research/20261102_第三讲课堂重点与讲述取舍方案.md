# 第三讲：课堂重点与讲述取舍方案

2026年11月2日。调研后提交教师审阅的方案；未修改现有讲稿、PPT、认可纲目或口播技能。

## 一、建议作出的主要改变

第三讲继续覆盖国家性质、政体和国家结构形式，但课堂不再按定义和条文逐项平均展开。建议抓三个需要教师带着学生理解的困难：

1. **为什么新中国的政权要这样组织社会力量：谁领导、主要依靠谁、还要联合谁？**
2. **大家都有意见，怎样形成对政府有约束的共同决定？**
3. **同一个国家，怎样在统一中安排不同地方的需要和制度？**

其中第一项必须提高比重。新民主主义革命的任务、工农共同处境与政治组织、人民民主专政的形成及其社会主义阶段含义，都是理解第一条的前提，不再只用几句标签带过。第二项用真正的人大预算审议过程，替换故事之后再补一大段机关关系的写法。第三项抓实际区域与制度选择，减少分类名称的反复辨析。

现有稿只作可复用的材料和段落来源。先决定整讲留下什么，再重新组织；不以给原来每一段增加一句解释的方式修补。

## 二、明确精讲、略讲与退出

| 处理 | 本讲内容 | 理由与最低保留 |
|---|---|---|
| **重点讲透** | 国家性质中的领导、基础、广泛联合；新民主主义革命与社会主义阶段的必要衔接；人民民主专政的含义与无产阶级专政的关系 | 这些关系是本讲困难核心。应由人的处境、真实政策选择和历史过程带出，再作准确归纳，不能以人口多、组织性强等词代替理由 |
| **重点讲透** | 人民参与、代表审议、人大形成决定、政府执行之间的关系；民主集中制 | 用一场真实预算审议中的不同主体与动作持续推进，不再分别重讲三四轮“产生、负责、监督” |
| **重点讲透** | 我国统一国家中的区域安排、民族区域自治与特区制度为何可以容纳差异 | 由广西区域安排的实际考虑和香港恢复行使主权后的制度接续展开，讲清共同国家归属与不同治理安排 |
| **短讲或借教材/PPT定位** | 国体、政体、国家结构形式的标准定义；人民与公民的基本区别；根本制度与根本政治制度；直接/间接选举的最低关系；四类国家机关名称 | 首次用到时交代足够背景，结尾归纳一次。代表个人与人大集体、选举与后续责任仍须出现，但不另设长概念单元 |
| **以图表和已有材料自读为主** | 行政区划完整分支、各类区域名称、国家标志与首都 | 教师只选择有辨认价值的具体例子，如北京、长沙、吉首。可看懂的名称不逐条口头复述，不默认学生已经完成课前阅读 |
| **退出本讲的深入展开，按既有课程接续** | 选举与监督主体的具体对应；各机关法定职权和内部领导体制；自治权类别和运作细目 | 第四讲已有选举来源与监督主体、民族自治制度作用；第七讲已有具体机关与自治机关职权。此处保留听懂本讲所需的最低身份，不提前重讲后课 |
| **退出这次课堂主讲，保留备课资料** | 国号全称/简称完整争论；七千人大会长叙事；德国四票案的详细诉讼与少数意见；国旗完整选图史；大字教材出版审批与版式的长过程；东深供水完整工程史 | 它们有价值，但同时铺开会挤掉本讲真正困难。不是将每篇压成一句“故事简介”后全部保留，而是实际作舍弃 |
| **直接删掉** | 面向制稿者的提醒、没有当前问题支撑的防误读说明、各页重复的同义归纳 | 不属于学生此刻需要经历的讲述。必要法定条件随实际问题说明，留一次准确解释即可 |

这不是把知识目标全部删去。改变的是课堂投入：书上可自行查读的定义降为定位，教师把时间用于学生难以仅靠定义形成的认识。第四、七讲的接收位置已读实际分纲核过；没有承接位置的材料，只标备读，不虚称“后讲会讲”。

## 三、上节45分钟：两个重要单元，一次收束

### 约25分钟：从天津搬运工人与《共同纲领》的选择，理解国家性质

建议用一个人的工作和一件具体物件进入。安力夫回忆1949年天津反“把头”的过程：搬运工人遭受层层抽取，货主又受到强制装运、过境收费等妨碍；他调查、汇报后，参与将分散的装运业务和工人组织起来。1950年工作报告还写到承运三联单，货主、公司、工人分别持有，列明货量、运价和经手人。

课堂可以先留下一个真正值得追下去的问题：**货主付的运费降低，为什么工人的生活反而能够改善？**从被抽取的钱、分割的运输业务和新的组织办法讲下去，学生先看见劳动者与经营者可能共同面对的实际障碍。采用当事人回忆和同时代工作报告，转述其记载，不虚构对白、心理、动作和精确收益比例。

接着把这个城市里的问题放回1949年建立新国家的任务。《共同纲领》一方面改变封建土地所有制、使农民获得土地，另一方面没收官僚资本，同时保护民族工商业；私营企业继续经营，又须处理劳动保护和劳资协商。几类人的利益和处境被同一份文件联系起来。

再进入已经核到的真实讨论：有代表主张把社会主义前途明确写进总纲；刘少奇、周恩来的公开讲话却说明为什么暂不这样写。教师在这里交代新民主主义革命的当前任务、领导力量和未来方向，让学生理解同一政治方向下为什么要分阶段采取不同办法。

工农联盟的理由随土地与城市劳动处境讲明：共同的反帝反封建任务、相互需要、农民作为主要力量、工人同农民的现实社会联系，不能缩为人数相加。政治领导则结合马克思主义理论对社会位置、组织条件的解释，以及共产党提出全国纲领、组织社会力量的实际过程，不能从“工厂里有协作”直接跳到国家领导地位。

归纳领导力量、阶级基础和广泛联合之后，还必须留下一个实际比较，不能把两个“专政”名称留到末尾匆匆解释：**同样叫人民民主专政，1949年与今天的社会制度和联合范围是否完全相同？**

这一部分在25分钟内明确保留约5分钟。先并看《共同纲领》第一、三条与现行宪法第一条、序言的有关表述；用教材印刷111—112页交代1954年过渡时期宪法、1956年社会主义改造基本完成这一必要变化。农业从个体经营向合作化、私营工商业通过公私合营等方式改造，点明被改变的实际经济关系，不展开各项改造的全部步骤。

随后再用教材记录的1982年修改草案中“即”改为“实质上即”的措辞变化，追问为什么既确认阶级本质，又保留人民民主专政的名称。比较必须回到前面已经见过的不同作用：谁提出并组织实施政治方向，哪些力量构成主要社会基础，哪些力量参加广泛联合。再回到现行宪法语境，说明人民民主专政作为我国社会主义国家政权的具体形式，与无产阶级专政的本质联系，以及工农联盟、广泛人民联合和历史发展所体现的中国特点。不能把1949年与今天直接画成等号，也不能只报“本质相同、形式不同”八个字。

民主与专政涉及国家政权面对不同对象、维护何种政治社会秩序；现行具体强制措施的法律要求，短调用第二讲已讲过的材料，不另开办案课。前20分钟的天津事件、土地和企业政策及建国争论，应为这一比较提供实际所指。若写成稿后这5分钟仍只能重复定义，就应调整前面的材料和铺垫，不能以“时间不够”再次省去。

这一单元是同一组人的处境和同一份建国纲领逐步展开，不分别给“新民主主义”“工农联盟”“无产阶级专政”各配一则小故事。25分钟包含必要背景、阅读、思考和归纳，不是25分钟材料之外再追加概念讲解。

**已核依据：**[安力夫当事人回忆](https://www.dswxyjy.org.cn/n1/2016/0115/c222139-28058928.html)、[1950年工作报告完整转录](https://www.marxists.org/chinese/reference-books/chineserevolution/mia-chineserevolution-195003.htm)、[刘少奇1949年9月21日讲话](https://www.gzzx.gov.cn/xxyd/llyj/202105/t20210518_143308.htm)、[周恩来9月22日报告](http://www.cppcc.gov.cn/2011/09/26/ARTI1317001119312787.shtml)、[《共同纲领》](http://www.cppcc.gov.cn/2011/12/16/ARTI1513309181327976.shtml)。工农理由另读[《中国革命和中国共产党》相关连续段](https://www.marxists.org/chinese/maozedong/marxist.org-chinese-mao-193912.htm)及[《论人民民主专政》](https://news.cntv.cn/china/20120629/108384_2.shtml)。两份文库转录未核纸本初刊，作为作者文本读取，不把全部措辞声称为初刊原话。

### 约17分钟：新河的预算已经改过，为什么还要继续审议

主材料建议改用2006年温岭新河镇预算审议，而不是七千人大会。同期现场报道里，代表颜友定质疑58万元“环卫综合楼”支出，镇长解释实际用途是垃圾中转站；次日修改方案将项目名写清，金额未变。随后代表继续讨论、提出预算修正，其中另案从预备费调50万元增加垃圾清运，经大会表决进入预算。

进入故事还可保留同一报道中的一个短细节：此前公众恳谈时，镇领导没有到场，一些参加者觉得不受重视；人大解释，这是当次为了让大家充分讲话所作的安排。到了正式人代会，政府领导则到场回答询问。两场会议中的不同安排，能让“给意见表达提供条件”和“政府需要面对审议”成为学生实际听见的事情。

随后让学生跟着代表的追问弄清：究竟在建什么，为什么需要知道用途后再判断；再看政府已经改过方案，代表仍能怎样提出具体修正。到了这个位置，“提出意见”“审议”“形成决定”“执行”已经分别有了人物和动作，教师再用简短的制度语言收束。保留一个连续过程，不把三场会议拆成三个各讲一段道理的小案例。

可以在镇长解释前、政府修改后各停一次，让学生想一想还缺什么信息、事情是否已经结束。不要求全班反复站队，不让课堂假设冒充当年的发言，不把学生是否猜中历史结果当作学习是否成功。

58万元设施和50万元清运是不同科目，不拼成同一项目增加到108万元；后案没有证据归给颜友定。案例主讲到人大作出决定，政府执行与向人大负责以当时法律交代；没有取得同批项目实施验收记录，就不编一个“全镇垃圾问题从此解决”的结尾。具体监督职权留第七讲。

这样，民主集中制通过信息进入、意见交锋、依法形成共同决定及组织实施来理解，不再单列一段抽象原则后反复复述。群众参加恳谈和人大代表在大会表决，是两个真实环节，身份在叙事中讲清。

**已核依据：**[2006年记者现场报道](https://news.sina.com.cn/c/2006-03-16/10529365212.shtml)、[当时适用的地方组织法官方存本](https://jgbz.sx.gov.cn/art/2013/2/1/art_1478853_17318335.html)、[1994年预算法官方存本](https://czt.hunan.gov.cn/czt/ztzl/lwpf/lwpfjxs/flzd/201411/t20141104_2905662.html)。这段不教授完整预算审查操作，不将当年试验细节说成今天所有地方通用程序。

本轮原先考虑泽国2005年30项项目与有限资金的选择，读完当年报告后降为备选：其数字与程序清楚，但具体分歧怎样展开主要还是汇总叙述，新河现场材料更适合当前课堂。大字教材保留在材料库，本轮不再占据另一个长单元。

### 约3分钟：只作一次知识收束

用前面已经经历的事情，说明国家的政治性质与权力怎样组织、活动是两个相联系的问题。定义对照教材确认，结束上节；不再把所有关系和原则重新完整讲一遍。

## 四、下节45分钟：统一国家怎样容纳差异

| 计划时段 | 实际讲述任务 |
|---|---|
| 约5分钟 | 看已有地图和地域关系，短定位单一制、联邦制与行政区划；北京、长沙、吉首作简短辨认，不逐项朗读全部分类 |
| 约12分钟 | 围绕广西区域安排的真实考虑：按民族重新拼区域会遇到哪些共同居住、铁路及经济联系问题；再看民族区域自治怎样安放在统一国家内 |
| 约17分钟 | 从香港恢复行使主权时“哪些改变、哪些延续”的真实选择展开，接到一份跨过回归日期的土地契约和原有法律如何继续调整居民生活 |
| 约6分钟 | 回看普通行政区域、民族自治地方、特别行政区的共同国家位置及不同制度根据；必要的中央与地方关系、联邦对照放在这里一次讲清 |
| 约5分钟 | 国家标志简要指认与全讲收束；给学生对照材料、用自己的话说明三组关系的时间，不再新增国旗长故事 |

广西材料采用周恩来1957年论述的具体比较，讲清是当时的制度考虑，不让它独自承担我国选择单一制的全部历史理由。统一国家的形成传统与当时的宪制选择作必要背景；“区域怎样划”与“组成部分在国家中是什么地位”须在所用材料中分清。国家结构的比较最后依宪法上的关系归纳，不只说统一、共同发展等价值口号。

香港部分以1982年会谈中分开的主权、回归后治理、过渡安排三个问题，以及1984年关于保留制度和生活方式的谈话为主；不展开全部外交谈判轮次、人物传奇和未经核实的现场动作。随后从基本法第8、12、120条观察法律连续性和地方身份，让学生感受到国家统一与日常生活接续怎样同时安排。澳门只作对应说明，不另起一则完整回归史。

**已核依据：**[1957年民族政策相关原文](https://tzb.taian.gov.cn/art/2012/8/2/art_75772_4661318.html)、[另一完整转载](https://kjmz.snnu.edu.cn/info/1016/1134.htm)、[外交部关于香港谈判与恢复行使主权的历史记录](https://www.mfa.gov.cn/ziliao_674904/wjs_674919/2159_674923/200011/t20001107_7950073.shtml)、[1984年谈话要点](https://www.locpg.gov.cn/jsdt/1984-06/22/c_125955746.htm)、[基本法第8条](https://www.basiclaw.gov.hk/sc/basiclaw/chapter1.html)、[第12条](https://www.basiclaw.gov.hk/sc/basiclaw/chapter2.html)、[第120条](https://www.basiclaw.gov.hk/sc/basiclaw/chapter5.html)。合同情形据真实法律规定提出，不假装存在有姓名的当事人个案。

德国四票案和东深供水史均留作备课或另一授课场合的材料，本轮不为保留此前工作量再把它们塞进45分钟。联邦制仍保留必要对照，中央地方关系仍由实际制度安排讲明。

## 五、调研对讲述方法的实际启发

本轮核读了Schwartz与Bransford的[原始学习研究](https://aaalab.stanford.edu/papers/time_for_telling.pdf)中实验设计及讨论部分，并回查[美国教育科学研究院指南](https://ies.ed.gov/ncee/WWC/Docs/PracticeGuide/20072004.pdf)关于具体与抽象表达相联系的建议。它们支持让学习者先辨认具体差别，再用有针对性的解释形成可迁移认识。研究主要涉及心理学及其他学科材料，并未验证本课的具体题材和时长；本方案的取舍仍是结合课程和教师实际反馈作的教学判断。

据此，课堂的体验可以来自先不揭结论、让学生面对当事人所见的信息和选择，再听到真实处理与后果；不必靠角色扮演、频繁提问或虚构对白制造热闹。主材料应真实承担理解工作，短小文化或生活补充仍可有自身趣味。概念用来在需要处命名、区分和收束，不在故事结束后重新铺一堂同样长的概念课。

## 六、原稿和课件如何处理

本方案若获认可，下一轮先按上述取舍重组上下节，再接回成立的原段与原件。不会按587行逐句补丁，也不会因重新组织而弃用已有可靠研究。完整成稿之后，再做一次面向教师连续讲述的整稿编辑；检查每次回顾是否有新增认识，是否让解释抢走了事情的推进。

现有PPT可继续提供条文、组织关系和地域图，但不再以38页全部逐页讲完为硬任务。略讲页可短指或留供查看，退出的故事页应跳过。新主材料需要相应展示，例如《共同纲领》的政策对照、新河两笔不同用途的经费；建议后续在授权范围内局部调整材料页。本轮只提出配讲需求，不制作或修改课件，也不先写一份正式PPT设计纲。

25、17及下节各时段都是取舍预算，已经包含材料讲述、必要解释、思考和收束；不是实际试讲时长，更不是字数配额。后续须据真正写出的整稿粗核双45分钟，不能用预写学生反应或慢读填时间。

现行技能第二步已经包含选材、重分篇幅、讲足过程和退出防御性说明。下一轮应围绕本方案选定的关键认识检查它们是否在正文实现，不再把每个定义都平均扩写，也不以出现案例名称作完成证明。此轮不修改技能。
