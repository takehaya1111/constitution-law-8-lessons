# S5—S6｜审稿、返修、教师评价与交接｜v0.3

按[总Skill](../SKILL.md)执行。只有作者自己检查时称自检；Codex仅在实际转交并执行后才可记为独立核证。文本核读不是出声试讲，教师认可也不是学生效果证据。

## S5｜拿着双纲与课堂方案审实际口播

输入为S0定位、S1目标与推进理由、S2依据、S3课堂方案和S4连续正文。不能只看稿件有无故事、有没有脚注或能否数到45分钟。

### 先查课堂是否真正向前推进

把实际稿件每个主要单元回答的问题写回S3方案，检查大纲核心知识是否讲透、浅讲内容是否挤占重点、故事是否带来了认识变化。一个单元结束时，下一单元出现的理由应清楚；不能只靠相同主题词或连接词形成假连续。

以无标题、无工作单的方式，从课堂第一句及各重要转场连续读。新生此刻是否知道在讲什么、为何要问这个问题？问句若需要偷看教师已经知道的答案才能理解，回S1/S3。不要规定所有开场必须先报时间地点，但必须能让听者进入。

检查相邻案例去留：删掉第二例会失去什么事实、解释、比较或必要的文化感知？若只有同一句赞美，合并或退出；若有作用，检查时间、主体与衔接是否准确。不同地方的事件不能编成直接因果。保留原已认可片段，并不免除其前后衔接的检查。

### 再查知识、讲述和深度

知识：核心事实、定义、法定职权、条件、历史时点、原典身份和重要推论均有依据。旧核证可复用，注明实际阅读范围；不能把搜索片段当原件全文，不能用教师认可口吻替代法源检查。

故事与趣味：人物、过程和值得讲的细节是否真正进入正文，而非案例名加抽象结论？典故及引文是否帮助理解，还是为显学识临时插入？故事的来龙去脉不能被删成梗概，但也不能把每个已显出的意思再赏析三遍。趣味不限于笑点，不消费受害者，不靠编对白制造戏剧。

推理：正面知识是否讲清、关键理由是否展开、异议是否值得认真回答？不能将“有助于”改成“必然”再反驳，不能用一句“两边都重要”代替具体办法，不能以古代寓言证明今日法律结论。

口述：是否直接面向学生说话？资料检索者是否突然成为课堂叙述者？“这个故事不只是”“这个比方到这里就够了”等编辑说明退出正文。保留正常解释与必要回顾，不机械追求句句短、段段金句。

### 最后核实际容量

完整课分别算两个45分钟，不能只报90分钟。每节时间＝最终口述量÷明确假定语速＋与口述不重叠的阅读、思考等活动。讲评已在正文、同时指读和正常停连不能重复计时。数字按拟定读法处理；若只作汉字粗计，必须注明限制。

复用已有tools/check_dual45.py前先核其读取的真实文字源，不得让旧生成器覆盖新稿。只改流程或方案时没有新口播，不重跑旧容量充成果。删赘述后不足就补必要解释或调整主次，不能靠慢读、空白、预设热烈讨论凑足。没有实际出声与记录，不宣称课堂时间通过。

## 发现问题后退回哪里

| 问题 | 优先退回 | 需要改变的工作 |
|---|---|---|
| 本讲目标或跨讲边界错 | S0 | 恢复认可纲和深浅边界，必要变化交教师 |
| 各段都有关但整堂不连贯 | S1 | 重排理解推进，不先修句子 |
| 知识依据不足、史实有误 | S2 | 核源、修正或收窄相应判断 |
| 故事真实却没有讲述价值 | S2 | 换有用材料或查承重过程，不能靠修辞挽救 |
| 材料贴不上知识、两个例子抢同一任务 | S3 | 调整职责和位置，必要时弃选 |
| 无前情设问、错误转场 | S1/S3 | 补前提或重排；不仅加一句“接下来” |
| 书面、同义重复、元说明泄入正文 | S4 | 定点重写可口述句段，保留事实和有效内容 |
| 复杂经典案例被压成梗概 | S2/S3/S4 | 恢复必要情节与解释，不只增加字数 |
| 时长不足或超时 | S3/S4 | 调主次与实际讲述量，再复算 |

修订同一受影响单元及必要承接，不无理由全篇重写。问题反复出现就检查上游决定，不能无限改同一开头。研究可否定初案；本次修订未涉及的已核材料继续使用。

## S6｜教师评价、保留和下一次复用

先交用户要求的对象：本轮要方案就交课堂方案；要口播就交可说的正文。来源和工序说明放后面，不先用长报告代替作品。

记录教师原话、所指版本、确认范围及失败环节。“看着还行”不能升格为正式验收；只读第一句的批评不能伪造为全稿评审。教师否定后更新真实状态，不继续把失败稿标作已审通过。反馈应改变相应工序，而非每次又多写一条空泛要求。

默认只有一张工作单与一份当前正文；方案、样段和修法可以放同单，旧全文在Git历史回查，不维持多个“最终版”。保存规范、史实、教学判断各自身份，不把旧工作单的阶段完成勾直接套在新版本流程上。

小单元认可后停在该单元范围；完整课只有得到对应授权才扩写。当前第一讲已转为先重做课堂方案，不因曾授权整讲写作就继续自动改稿。未来配套制作由Codex按教师认可的确切正文版本另行完成，不在排版时二次全面润色；PPT、Word、PDF不是当前流程校准条件。
