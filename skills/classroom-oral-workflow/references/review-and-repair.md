# S5—S6｜审稿返修、教师验收与交付

按[总入口](../SKILL.md)执行。审稿要使产出更好，不是生成越来越长的审计报告。采用已有蒸馏技能的quality-checks与以下课程条件，不重建评分平台。

## S5 审稿员：既检查不能错什么，也检查应该写出的东西有没有写出来

**接收：**S0任务、S1关键事实和来源、S2选材理由、S3讲述蓝图、S4正文。只看正文而不知任务，不能准确判断是否跑题。

默认由Codex在教师转交后作核证和独立问题检查；当前Pro单独执行时先完成内容和语言自检，明确“自检、未获独立核稿”，不冒充另一模型已经审过。独立审阅不是每次出样段的前置门槛，更不允许假装自动调用另一个会话。Pro最终负责重要学理取舍，教师负责实际使用认可。

### 五项不可互相抵消的检查

| 检查项 | 具体核什么 | 不合格的实际表现 |
|---|---|---|
| 知识与依据 | 逐项核承重事实、主体权限、条件、原文与历史时点；重要推论不超过依据 | 故事真实但教出的规则错误；转引被冒称原典；先后被说成唯一因果 |
| 故事与选材 | 材料为什么值得讲；关键处境和动作是否保留；来龙去脉是否使知识可理解 | 只有名人标签；经典案例被压成梗概；只剩“出问题—整改—改善” |
| 口语与连贯 | 首次听能否跟随对象、动作、前因后果；句子有自然承接 | 报道口吻、来源作者突然插入、抽象词互释、显然答案的长串问答 |
| 理由与深度 | 正面知识讲明了吗；案例后是否真的解释；异议是否有分量；结论是否相称 | 只批判、无正解；弱反方；一句“都重要”代替办法；金句扩大结论 |
| 任务与容量 | 完成了本次解释而非另开课；长度与复杂度匹配；实际口述统计可靠 | 为短而删关键情节；为足量而复述灌水；局部估算冒称整讲双45通过 |

没有综合分抵消法学错误，也不因语言漂亮而宣布教师认可。可选修辞并非每段硬指标；全讲的必要元素依旧必须有实际落实，不因局部不用比方就取消整课故事性。

### 2026-10-09 全讲叙事与文化质量门槛：不能靠知识覆盖和字数抵消

教师对`ORAL-LECTURE1-001`第1版完整候选的实际评价是“故事性、趣味性还是不足，也没有引经据典，就是非常流水账的平铺直叙而已，讲的很大很浅很严肃，就是一堂非常普通的课”。此前S5写了“十二小节都有、脚注齐、180字/分钟接近45”，却没有检验这些是否成为有张力、有人物、有学识且有思辨的口播。**这次反馈明确表示那版S5的风格审查失败；时间合适≠课堂风格合格。**

以后审完整一讲，除了上表五项，还要做一次**听觉和结构上的反例检查**：连续浏览上下节相隔较远的实际正文，尝试不用术语而用具体人物、行动或原句复述其中的核心认识。遇到大片“先问—当然不是—所以重要”而找不到事件、引用、机制或真正异议，必须标出原段，退回S2（缺可讲材料）或S3（材料虽有但没有形成故事节奏）。不能只说“有故事和案例”就勾过。

遇教师要求趣味、学识和引经据典时，须指出**实际选用了哪些古典原文、当年同期史料、文化背景，且各自如何改变法律认识**；只列链接与典故名称不通过。真实典故不是数量配额，不能用愈加生僻掩盖没有关系的铺陈。严肃案件可以让人认真，趣味不意味着用受害者遭遇制造笑点；可通过人物的真实选择、成语的原场景、历史制度的意外差别和带理由的反问形成可听的趣味。

审阅者可在工作单用几句话记录“哪段平，为什么平，缺的是什么，返回哪一岗”，不另建打分表或全量引用审计。教师否定以后不得继续把旧版本标作`AWAITING_TEACHER_REVIEW`并默认通过；先记录`TEACHER_REJECTED_STYLE`和实际返工，新的候选仍标`PENDING`。**一轮新候选未获教师判断前，不因自评有趣、引用更多或字数达标就称问题解决。**

### 第一屏开场与跨段冷读：交稿前实际检查（2026-10-10校准）

首轮第一讲v1因故事不足被教师否定；v2补入史料和典故后，**教师只读到第一个人为设问就指出开场没头没尾**。这说明“有多少典故”“能否从全文回述主线”仍不能代替**听者从零进入前60—90秒**的检查，S5再次漏检。教师没有评价v2其余全文，不能由此夸大为每一段都被否定。

S5除了原有知识、选材、篇幅检查，还须实际拿**每个重要单元的开头及前一个单元末尾**做冷读：第一句若去掉标题，能否说清已在谈什么？问句是否在出现以前已经有足以让听者关心的前情？人物和经典是否先交代所在时代及必要身份？上段是否提前说破下段悬念，或下段把上段三分钟前的内容错当刚讲？若无法在不偷看作者大纲的情况下跟住，应认定**S3讲述编排未通过**，不能把整稿标为S5合格并要求教师继续替模型查错。此项是对真实失败的返工门槛，不新增计分平台。

这次定位还发现三处同源迹象：豆选段前一句已提前揭示豆子选票，紧接着认可段又问“一颗豆子能不能当选票”；修宪段开头连续两次重问“根本法能否修改”；下节前文刚讲孙志刚，却用“刚从郑人买履回来”衔接。已在同一候选内更正这些局部问题，不据此冒称全讲其他转场都经过真人听课验证。

### 发现问题后，直接指定退回位置

| 具体反馈/缺陷 | 先回哪里 | 修改什么；哪些保留 |
|---|---|---|
| 事实、引语或规范不可靠 | S1知识研究 | 补核或修正该事实及受影响的推论；其余无关文字不重写 |
| 真事不典型，像编的例子也能替代 | S2选材 | 重新寻找有解释力的真实细节或换材；不继续靠口号装饰 |
| 孙志刚那样的复杂故事被摘要化 | S2→S3 | 恢复承重事件链与必要背景，再排知识进入点；不是无差别加细节 |
| 东讲一句西讲一句、故事与概念两张皮 | S3编排 | 重排相关内容单元、补理由连接；不能只加“接下来” |
| 太书面、日期报站、指代不明 | S4主笔 | 直接改口述句段和叙述顺序；不是统一加“同学们、其实、在” |
| 首饰盒式赘述、同义循环 | S4主笔 | 删重复释义与教学效果自述；保留新生不懂的专业背景 |
| 无真正思辨或结论跳得过大 | S1或S3 | 补证据与判断标准，或收窄结论；不硬造反方 |
| 听完仍讲不出发生了什么 | S3/S4 | 补主体、行动和转折的可追踪关系；文本复述检查不称学生效果试验 |
| 总时长不合适 | S3/S4 | 调主次、补缺少的必要解释或压缩次要复述，再计算；不故意拖慢 |

审稿只交需要行动的问题：原位置、问题、影响、应返回哪岗、保留什么。主笔修后复核受影响部分，再连续通读承接。不能让审稿员无理由重写整篇、形成第二套文风。

**反复失败的处理：**同一问题在同一材料上经过有针对性的修改仍然出现，就检查上游假设或选材是否错误；不要无限执行“再自然一点”。短段已被教师认可后冻结正文，仅在有事实错误、新任务或教师明确反馈时修改。改变工序办法后，后续用不同难点验证迁移，不以原段越修越顺证明流程普适。

**S5产出：**修订后的单一正文；短问题/处理记录；实际核查范围与仍存限制。已解决的普通小错不另写长报告。

## S6 教师验收与维护员：把反馈变成可复用经验

**接收：**S5后的正文、必要依据、极短说明。交付顺序：先给正文，再给来源与本轮改动；不先念七岗工作总结。

教师说“这段达到要求”，仅记录相应文本和认可方面；“看着还行”如实保留，不升级为所有事实、全部流程或学习效果的正式认证。没有反馈标“待教师评价”，不能自动通过。

记录只需：样本/版本＋教师原话＋问题环节或认可点＋实际修法/适用边界。沿用同一工作单，不每次新建经验库。可将明确且可迁移的经验补入[source-map-and-feedback.md](source-map-and-feedback.md)相应条目，不因个别措辞偏好修改全部工序。

**阶段停止：**本次约定的小口播单元交付后即停止，不顺课序接写、合稿、配图或导文件；除非教师明确要求继续。用户请求一次完整工作流执行时，S0至S5应在授权范围内连续完成，不在每岗仅交计划后等待确认。必要材料冲突如不影响主线可局部收窄；真的改变已认可大纲或核心教学命题时，交Pro/教师裁决。

## 必要元素怎样保留，而不成为每段模板

| 原有必要元素 | 最小口播如何落实 | 正式整讲增加什么 |
|---|---|---|
| 知识完整准确、自然中文 | 在本次范围内讲明白、可说 | 核大纲全部覆盖和主次 |
| 整体推进、故事与知识来路 | 小单元有真实内容和承接，不只概念摘要 | 故事贯穿但不堆积，前后知识形成体系 |
| 真思辨、精辟切题、人的处境 | 在确需的关键处体现，不能只贴标签 | 全讲至少存在实质实现，不设固定数量 |
| 回顾、收束、预告、双节结构 | 只有任务是独立开场/结尾时才按其位置写，不伪造前文 | 上下节各自成立，首次课不虚构前课 |
| 真实的思考与反馈条件 | 有需要才留阅读或问题，不演学生反应 | 使用活动时材料与完整讲评相配 |
| 课堂容量、稿屏使用 | 只报局部估算，无PPT不造页号 | 分别核两个45分钟；PPT形成后核真实翻页提示 |

## 时间与交付的实用规则

小单元统计真实口述；标题、来源、编写说明、模式编号不算。阿拉伯数字按预定读法处理，未统一口读时标明粗计数，不用一个字符代替一串读音。既有140/150/180/200/220字每分钟仅作敏感性假设，180不是教师实测；没给严格时长时不拿它压缩复杂故事。

正式整讲：本节时长＝口述量÷所用速度＋与口述不重叠的活动。教师讲评、同时看原文/指读不能双计；两节分别统计，不能只报90分钟。使用仓库既有tools/check_dual45.py，先核它读取的真来源，必要时最小适配，不能让旧生成器覆盖新稿。当前不为没改的整稿重跑。

## 认可正文怎样交给Codex产生使用文件（本轮不执行）

交接必须给出：认可正文路径与提交/版本、确认范围、目标文件类型，以及正文不得在排版阶段二次全面润色的要求。Codex负责同版排版、导出、文字与实际渲染核验；发现知识问题退回内容岗，不静默改已认可含义。PPT需要另经授权开展审美与技术路线研究，不能把一键制作当新主笔。文件齐全不是当前流程成立的必要证明。
