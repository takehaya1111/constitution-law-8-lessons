# S5—S6｜审稿、反馈诊断与交接｜v0.3.1

按[总Skill](../SKILL.md)执行。作者自己检查称自检；只有实际转交并由Codex执行，才记为另一方核证。文本审查不是出声试讲，教师认可也不是学生学习效果证据。

## S5｜对照双纲、课堂方案和实际正文联合审查

输入是S0定位、S1理解推进、S2依据、S3整堂课方案及S4正文。不是只查故事是否出现、法条是否齐、字数是否够45分钟。对整体质量的结论应同时覆盖知识主次、真实内容、自然口语、材料解释力、衔接和两节容量；任何一项明显失败，不用另一项的优点抵消。

### 先查实际教学目标，不按材料名称判断

把正文主要单元真正让学生理解的关系，与认可大纲逐项对照。核心内容是否讲透？例证是否变成程序培训？案例后学生能否离开其人名和条号，解释本讲的宪法学问题？同一材料出现多次并不自动错误，每次有没有真实新增的事实、关系、理由或应用才是依据。

审相邻材料：删掉后一例会损失什么？只有同义赞美就合并；承担不同职责则检查时间、主体和关系。不同地方、不同人的事情不能编成直接因果。认可旧段不免除对其新位置和承接的检查。

去掉标题、大纲和任务单，从课堂第一句及重要转场连续读：初听者知道在说什么吗？问句是否已有让人关心的前情？下一段为何出现？不能靠“再看一个故事”替代联系，也不要求所有开头必须报时间地点。

### 再查知识、材料、思辨和声音

知识：事实、定义、法定主体、条件、版本、原典身份和重要推论有对应依据。旧核证可复用但说明范围；搜索片段不当全文，教师认可口吻不替代法源核验。历史规范不冒充现行法。

故事：需要的处境、行动和关键转折是否真正进入正文？经典是否讲出原场景和与知识的关系，而非报人名？复杂案件不能压成梗概，已显然的日常意味也不要赏析三遍。文化细节可以帮助进入时代，不要求每一句都独立证明一个法条；但人物痛苦不作笑点，不能编对白和心理。

思辨：正面知识讲清了吗？异议是否真实而值得回应？有没有把“可能”改成“必然”来反驳？“两边都重要”之后有没有实际判断办法？古典寓言能帮助理解，但不能成为当代法律结论的证据。

口述：检索者、编辑者是否突然进入教师的嘴里？删除“这个故事不只是”“现在给这个假设再添加条件”“这个比方到这里就够了”等写作指令，必要的设例身份用自然方式一次交代。保留需要的解释与回顾，不追求每句都短、每段都金句。

### 最后核容量，但不能等到最后才发现无内容

S3预算须由具体材料、学理解释和课堂动作支撑；仅有“深化11分钟”的名称不能交主笔填充。S4可以反证预算，不能靠复述、无效问题或无关情节写够分钟数。

最终分别核两个45分钟：口述时间按实际正文及明确语速假设计算，再加真正不重叠的独立阅读、思考等。讲评已写在正文、边指读边讲以及正常停连，不重复计时。数字按拟定读法处理，未折算须标汉字粗计。没有真人记录，不称已测定教师语速或课堂时间。

先核tools/check_dual45.py是否读取本次真实源，再决定复用，不能让旧导出器覆盖新稿。只做方案时没有新全文字数；表格加起来90不是口播容量通过。删短后应检查必要理由是否被误删、其他单元是否还缺深度，不把所有删掉字数都称为废话，也不靠放慢或虚设互动填空。

## 教师指出局部问题后，先诊断全局再编辑

执行总Skill的共同闭环，以下是S5/S6实际操作。**用户说“这段啰嗦”是确切的失败反馈，不自动等于命令把它压成最短稿。**

用原工作单中的简短记录回答四件事：

- **表现与约束：**哪一句、哪一段、哪一版出了什么问题？哪些认可内容、故事要求和45分钟条件没有改变？
- **根因与证据：**是措辞重复、故事牵强、概念没讲清、材料职责错位，还是上游时间和知识主次失当？用大纲与实际段落判断，不凭最新评价直接选一种修法。
- **修改与影响：**最小但足够的修改范围是什么？会减少哪些口述内容、影响哪些前后承接或知识解释？只有根因在上游时才重排相应单元，不无理由重做全课。
- **复核与状态：**修改后局部问题是否改善，同时有没有漏知识、丢故事、制造重复或失去容量？未解决的影响明确写出，不能改一项就报整体通过。

**本项目反例的实际用法：**24分钟赔偿长稿被指冗长，先查人物条件为何这样编、必要解释是否被操作细节挤占、24分钟是否有内容依据。直接删到8分钟后再扩另一史料15分钟，不等于完成诊断。反过来，也不能据此宣布国家赔偿这个大纲已选窗口应全部废弃。正确改法须同时说明保留的宪法学关系、撤除的无效情节、各段新分工和全节时间影响。

反馈原则适用于所有阶段，不把“先查整体”做成每次开新研究项目。句子层的问题可当场定点修；改变教学中心、认可知识范围或授权边界时，才需要相应重新判断。教师不用代填检查表。

## 根因确定后，退回对应工序

| 根因 | 返回 | 实际修改 |
|---|---|---|
| 目标、主次或跨讲边界不成立 | S0/S1 | 恢复认可纲及核心认识；重大改变交教师 |
| 各段有关但全课不连贯 | S1 | 重新安排理解推进，不先修连接词 |
| 知识、史实、规范版本不足 | S2 | 核源、修正或收窄判断 |
| 材料没有讲述价值或无法支持关系 | S2/S3 | 比较替代、查关键过程或弃选，不靠修辞挽救 |
| 例证抢占知识中心、单元承担不合理时间 | S3 | 改材料职责与内容分配，并检查整节和另一节接口 |
| 无前情问句、错位转场 | S1/S3/S4 | 根据根因补前提或重排，不只加“接下来” |
| 书面、重复、编辑说明混入口述 | S4 | 保留有效知识与故事，改成连续自然口述 |
| 复杂故事失去承重情节 | S2/S3/S4 | 恢复事实和理由，不能只加字数 |
| 删改后不足或超时 | S3/S4 | 连同知识和风格一起调整后重算，不单指标补时 |

修复的是根因及其受影响下游，不是只修发现问题的位置，也不是无差别重写整个仓库。反复失败应复核上游判断；此前未受影响的已核资料继续使用。

## S6｜教师评价、留存与接续

先交用户实际要求的对象：要方案就交课堂怎样讲，要口播就交能说的正文；来源和工序放后面。记录评价的原话、版本和认可范围，不将“看着还行”升级为整讲验收，不把只读一句的批评写成全稿审查。

教师否定后更新真实状态，实施上述全局诊断；不要默认最新意见取消此前全部要求，也不反复让教师确认同一大纲。反馈涉及不同质量目标时应联合解决，不以优先级口号掩盖实质取舍。

同一任务一张现行工作单、一份当前正文；旧全文与日志用Git固定提交保存，不层层叠加冲突的当前状态。方案、样段、作者自检、独立核证、教师认可与学生效果分别记。

样段认可只在对应范围内有效；后续是否扩整讲按实际授权，不无限重复小样本，不因一次成功放弃全课检查。未来Codex按教师认可的确切正文同版制作配套，不在排版时重新决定教学内容。
