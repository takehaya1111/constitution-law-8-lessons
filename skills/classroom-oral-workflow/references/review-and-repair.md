# S5—S6｜联合审稿、反馈诊断与复用｜v0.3.2

按[总Skill](../SKILL.md)执行。作者检查称自检，只有真实转交且Codex执行才称另一方核证。文本审查不是出声试讲，教师认可不是学生效果证据。具体当代融合操作与研究见[融合说明](contemporary-integration.md)。

## S5｜拿双纲、课堂方案和实际正文联合检查

输入为S0定位、S1推进、S2依据、S3整讲方案、S4正文。不是只查故事有没有、法条齐不齐、字数够不够。主次、知识、自然口语、故事、当代联系、思辨、衔接和两个45分钟应共同成立；一项明显失败不能拿另一项补分。

### 先查教学任务和课堂连续性

把各单元实际让学生理解的关系与认可纲对照。核心是否讲透，例证是否成了程序培训，离开人名和条号还能否解释本讲的宪法学问题？同一材料出现多次不必有错，但须确有新的事实、理由、关系或应用。

相邻材料的职责要清楚：删后例会损失什么？同义赞美可合并，互补职责可保留，时间、主体和关系仍须核。不把不同工厂、人物、新闻拼成直接因果。认可的旧段放到新位置，同样检查前后。

去掉标题和任务单，从课堂第一句、重要转场及段末连续冷读。初听者知道在说什么吗，问题有无前情，为何下一段出现？“再讲一个故事”不自动提供关系，也不规定所有开场都必须报时间地点。

### 知识、故事和推理仍须审实物

核心事实、定义、法定主体、条件、版本和重要推论须有依据。旧核证可复用，但说明实际范围；搜索片段不当全文、教师认可口吻不替代法源。历史文本、现行规则、报道、评论、二创、原典和新设例身份分别准确。

故事有没有处境、行动及关键过程？典故是否讲出原场景和用途，而非人名标签？复杂案例不能压成梗概，显然意味不反复赏析；文化细节可以帮助进入时代，不必句句证明法条。不得编对白心理、教师亲历、学生反应或把苦难作笑点。

正面知识有没有讲清？异议是否真实且值得回应？是否把“可能”改成“必然”再反驳，或用“两边都重要”代替判断办法？类比帮助感知，不为今日法律结论提供独立事实证明。

### 当代融合分两类结果检查，不让它变成又一个局部指标

**可听与亲和：**不熟原梗的人是否仍能跟上，教师是否能用自己的话自然说出，是否要长篇解释笑点？整体语气有无正常交流、机智观察与轻松片刻，还是每句话都端着？悲剧和严肃分析可保留相应语气，不强配笑话。短小的关系型表达有正当作用，不逐句要求证明法律命题。

**理解与整体：**承担教学任务的新材料，是否真正提供事实、比较、理由或迁移，而不只是与法律共享关键词？它替换了什么旧说法、占用什么时间？是否挤走知识、打断故事、抢进后讲，或把最新但未定的消息写成法律结论？不能因幽默赢得笑声就报理解通过，也不能因一次没笑就判教学失败。

具体冷读“前句—融合内容—后句”。如果前句只是“最近有个热搜”，后句只剩“所以宪法很重要”，中间尚缺教学转换，回S2/S3，不只让S4增加口头禅。如果所有边界都正确却不自然，检查正文是否塞入过多编辑说明和逐句防误读声明；必要专业条件应讲清，后台核查过程不必念出来。

新材料核语义、来源、发生/发布/施行时点与当前进展；不把平台播放量视为全班熟悉，不把广告或二创当事实。核验范围不够则收窄用途、替换或暂停，不能用“当下很火”越过证据要求。

**补充研究依据：**Bradley与Hackathorn《You Don't Have to Be a Stand-Up Comedian》，2025-08-28在线发表、编入2026卷期，[出版社摘要](https://journals.sagepub.com/doi/10.1177/00986283251369750)报告287名本科生问卷，将轻松愉悦的课堂氛围与教师幽默区别研究，前者与师生关系、满意度有较强关联。本轮只读摘要，不能作因果或学习成绩结论。与[融合说明第二节](contemporary-integration.md)的实验研究合看：本项目要检查整堂课的亲和，而不是把教师变成段子演员；这种取舍属于教学设计，仍需实际反馈。

### 口语与容量不能最后才发现问题

口述不应突然出现检索者、编辑者的话。删除“现在给假设加条件”“这个梗很好笑”“这个比方到此为止”等幕后指令，必要的假设身份自然交代。保留真正需要的解释与回顾，不追求句句短、段段金句。

S3预算须有具体材料、学理和课堂动作支撑，只有“深化11分钟”不交主笔填字。S4能够反证预算，不能靠复述、假问题或无关情节写够分钟。

分别核两个45分钟：实际口述量按明确语速假设计算，再加不重叠阅读、思考等。写入正文的讲评、边指读边讲和正常停连不再重复计算。数字按拟读法折算，未折算则称汉字粗计。没有真人记录不称教师语速或课堂时长已测。

使用tools/check_dual45.py前核是否读取真实源，不运行旧导出器覆盖新稿。只改机制或方案时没有新全稿计数，时间表加总不证明容量。新增新闻、幽默或文化背景同样占用时间，应先替换冗余，再检查全讲；删短则看有无误删理由，不用空白或放慢凑数。

## 收到局部反馈：先诊断全局再动笔

按总Skill闭环，在原工作单简述四件事：

- **表现及不变要求：**哪一版哪里有问题？认可大纲、故事、深度、当代联系、自然表达和课时有哪些仍须保留？
- **原因与证据：**是措辞、材料适配、知识准备、课堂推进还是时间任务导致？用实际稿和纲判断，不先选修法再证明。
- **修改及影响：**最小充分范围是什么？会改变哪些知识、故事承接与时长？根因在上游才重排，不因一条新反馈全库重做。
- **修后复核：**局部改善是否造成别处退步？必要知识、有效旧段、当代联系和两个45分钟能否共同成立？未解决的不能隐去。

“赔偿案例太啰嗦”不自动授权删成最短；“太严肃、不时髦”不自动授权插遍热梗。前者要查24分钟任务和人物条件为何失效；后者要查语境研究、教学转换和表达是否缺位。既不全删国家赔偿窗口，也不因新材料可得就改变课程中心。

先查整体不意味着每次开研究项目。局部句子可定点修，改变教学中心、已认可知识范围或授权时才重新交判断；教师不用填检查表。

## 依根因返回工序

| 根因 | 返回 | 实际修改 |
|---|---|---|
| 目标、主次或跨讲边界失当 | S0/S1 | 还原认可纲与核心认识，重大改变说明 |
| 各段有关但整课不连贯 | S1/S3 | 重排理解推进，不只修连接词 |
| 知识、史实或现行版本不足 | S2 | 核源、修正或收窄 |
| 素材有热度却无具体教学用途 | S2/S3 | 重做转换、比较替代或弃选，不以新词补缺口 |
| 案例或新闻占据知识中心、时间无内容支撑 | S3 | 调职责与内容，连同两节复核 |
| 无前情问句、错误转场 | S1/S3/S4 | 依原因补前提或重排 |
| 语言书面、重复、梗讲不自然或元说明泄入 | S4 | 保留知识和有效故事，重写实际口述 |
| 复杂故事失去必要过程 | S2/S3/S4 | 补回事实和理由，不只加字 |
| 内容过时或事件更新改变原判断 | S2/S3 | 重新核证并改相关论证与承接；纯口吻可直接替换 |
| 修改后短缺或超时 | S3/S4 | 和知识、风格一起调整再算 |

修复根因及受影响下游，其他成立内容继续复用。反复失败须复核上游决定，不无限精修同一开头。

## S6｜教师评价、再次授课与交接

先交实际任务的对象：方案就交怎样讲，口播就交能说的正文；研究过程放后面。记录教师原话、所指版本与范围，不把“看着还行”放大为整讲验收，不把只读一句记成全稿评审。

教师批评应改变对应工序，不取消以前的有效要求，也不每轮重批大纲。同一任务一张工作单、一份当前正文，旧全文和过程用固定Git提交回查，不层层叠加冲突状态。

复用前把稳定知识与时效材料分开处理：关键新闻反转、法条更新、语境误读必须改相关判断；只是表达过时可换成普通说法。教师或实际学生反馈可更新对熟悉度的判断；没有反馈不猜全班反应，不以热度替代教学效果。具体撤换规则见融合说明，不新建监控系统。

样段认可仅限该段，后续扩写按实际授权。未来Codex依据认可的确切正文制作配套，不在排版时重定课程。文件已写、作者已审、另一方已核、教师已认可、学生实际学会分别报告。
