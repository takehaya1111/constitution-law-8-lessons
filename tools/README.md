# 双45分钟容量复算

从仓库根目录运行（仅用Python标准库）：

```powershell
python tools/check_dual45.py --input 'materials/第1讲整合试讲主版本/口播容量输入.json'
python tools/check_dual45.py --input 'materials/第2讲实质备课/容量输入.json'
```

默认生成输入同目录的`07_双45分钟容量报告.json`和`.md`。`--output`可指定报告前缀。程序从当前主稿中指定二级标题下的全部“讲述”三级段读取文字；非口述活动、来源、备查、未选择备用段不计入口述。报告保留源文件、输入、脚本的SHA256、实际命令、执行时提交、逐段源行号、口读修正与每条路径累计时间。

2026年10月8日第一讲新口播采用`source_layout: continuous_markdown`：二级标题分上、下节，十二个三级标题映射实际正文。提示方括号、脚注编号、标题及文末教师附注排除；四次独立阅读/思考另计。源始终是当前Markdown，程序只读，不写主稿。旧`容量输入.json`及旧内容JSON保留历史，不用于新稿；第二讲原格式仍兼容，本次没有重算或制作第二讲。

连续稿的报告先列同一默认主线及五语速、三独立停留情景，没有另外的短讲/深化选择。纯汉字不含`〇`，口读量计入。全部小节必须映射、不可重复或跨节；遗漏和重复会报错。

## 最小输入约定

- `source`与`source_sha256`：同目录主稿及其校验值。正文改变后，内容负责人先核映射、活动和路径，再更新校验值、重新运行。程序不会自行接受旧校验值或修改正文。
- `blocks`：编号、上/下节、主线/深化/短讲、二级标题和“讲述”标题。短讲的`replaces`指向原主线编号（或按主线顺序连续的编号数组）；深化的`insert_after`指向本节主线。编号与源标题不可重复。
- `activities`：所处段落及`plan/short/slow`独立秒数；以`description`写实际任务、`scenario_reasons`写具体加减依据。教师讲评应放入讲述；`includes_teacher_feedback`须为false。与口述重叠的活动标记`overlaps_speech:true`，不另加时。
- `selections`：上下节、五档速度、按计划/回应短/推进慢顺序写三个选择。`main`表示主线；`C1+C2`表示互斥替换对应主线；`E1+E3`表示仅加入这两个已写完整的深化。短讲保留原任务活动。工具不自动决定教学取舍。
- `speech_readings`（选填）：特定写法到实际汉语读法的映射，例如`{"PPT":"演示文稿"}`。数字、百分比、分数、条号自动修正；1500—2099四位数在本课历史语境中按年份逐位读，其余按整数读。字母缩写按中文近似音节估计。若不是这种读法，必须明确覆盖；未知外文报错。
- `supporting_sources`（选填）：教学安排等同目录文件，用于把活动依据和检查点文件的校验值一并锁定。

每节预测时长为实际选用口读量÷假定速度＋不重叠活动时间。140/150/180/200/220均是分析假设，180是暂定编排参照。42—45分钟仅作为报告提示用的编排参考范围；较大空余与超时均明示，不能据程序通过宣称严格45分钟或学习效果已验证。

程序检查来源未错版、两节齐备、全部讲述有映射、互斥替换、无跨节或重复来源、活动不重复计教师讲评、重叠处理和累计算术。它只验证显式数据声明，不能判断活动是否真实合理、内容是否足够深入。采用中途调整时只替换尚未讲出的整段；已经讲出的长稿不能再从头读短稿。
