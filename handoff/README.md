# Pro与Codex交接说明

## 本轮

- 目的：前七讲诊断、总体完善方案和一讲试做任务。
- 材料基准：本次初始提交，文件入口为 `START_HERE.md`。
- 当前没有已收到的Pro诊断；不能把任务说明当成Pro已经审阅的结论。
- 传递者：授课教师。Codex只在教师转交消息或另行明确授权后执行后续要求。

## Pro返回意见时

建议按以下顺序组织，允许根据实际问题调整：

1. 实际读取的文件和页段，以及无法读取的材料。
2. 核心诊断与优先顺序；具体到课次、文件位置或教材章节。
3. 每讲保留、补充、压缩和仍待核实的内容。
4. 一讲试做任务：要回答的问题、需要的材料、教学设计要点、成品和检查标准。
5. 需要教师决定的真正教学取舍；不要把格式或工具小事都交给教师。

## Codex执行后

每次交接写一份简短说明，列出本轮课次、对应Pro意见、实际修改、来源证据、新成果路径和仍需判断的事项。附本轮提交版本，便于Pro始终审阅同一批文件。涉及原定教学结构的重要变化，由教师决定。

不以“我认为完成”替代成品；不以两个模型意见相同替代材料依据；不反复转交单个字号等可直接处理的细节。交接集中在总方案、一讲样稿和分批成果几个节点。
