## 一、这堂课怎样推进

**上节：从国家需要作出的根本安排，讲到这些安排怎样组织并约束国家权力。下节：把视角落到一个人的赔偿请求，看根本要求如何经由具体法律、承办机关和实际工作得到落实。**

不是把两个问题各说一遍。上节解决“宪法规定什么、为什么具有根本地位”，下节解决“既然宪法有约束力，为什么仍须立法和履职”。两节共同回答本讲已认可主题：宪法是什么、为什么是国家根本法、怎样联系国家权力和公民权利。

- **上节推进线：**1954年为什么要认真讨论并制定宪法 → 宪法究竟作出哪些根本安排 → 权力属于人民如何进入制度 → 机关已经产生、有规定可依，为什么仍须追问行为和规定的根据 → 把这些要求归纳为本质与基本原则 → 根本规则怎样依法修改。
- **下节推进线：**受侵害者凭什么提出赔偿请求 → 仅有根本权利依据还不能回答什么 → 谁负责、怎样使请求能够被依法判断 → 普通法律增加办法是否等于重新决定宪法有没有效力 → 法律公布之后还有哪些必须由人完成的工作 → 区分规范、制度、履职与实际保障。

这是Pro的教学组织选择，**不是史料原有的统一叙事、不是教师已经认可的新方案**。知识深浅沿认可纲，材料顺序和份量供本轮教师审阅。

## 二、S0定位与预期理解

依据：[八次课内容分配](../materials/宪法学八次课教学内容总表_讨论稿.md)、[第一讲七项知识纲](../materials/第1讲整合试讲主版本/内容提纲.md)。第一讲建立根本法、最高效力、基本原则和法律具体化/实施的入口；第二讲展开形成发展，第三至七讲展开制度、权利与机关，第八讲展开实施监督。**不在第一讲完整讲宪法史、收容遣送制度史、国家赔偿程序或备案审查。**

听者为公安专业一年级。暂以“可能听过宪法、人民当家作主、依法办事，但尚未系统掌握规范层级和机关关系”为设计起点，**不是已经测得的学生水平**。首次课不虚构上次所学。

本讲结束时，希望学生能够做到：

1. 不只说“最重要”，能用根本事项、最高效力、特殊修改程序解释根本法；能在现行文本中定位相应内容。
2. 区分国家权力属于谁、由什么机关行使、一次具体行为是否合法；知道宪法既组织权力又要求其依法活动、保障权利并接受监督。
3. 面对一个给定的行政赔偿请求，说明宪法确认什么、普通法律增加什么、机关还必须实际做什么；不将“有条文”与“现实已经落实”混同。

下面的三次理解检查只检验解释是否成立，不新增考试系统，不预编学生举手、答错或掌声。

## 三、上节45分钟：根本规则怎样组织并约束权力

> 时间是**教学预算**，包括本行教师说明、阅读、必要停顿和讲评，不是新稿口读实测。知识步骤不等于强制PPT页或朗读栏目。

| 时间 | 这一步实际怎样讲 | 学生应多理解什么，为什么接下一步 |
|---|---|---|
| 0—7分钟｜根本规则的来路 | 用1954年长辛店工人讨论宪法草案的同期报道作短入口：先交代草案公布、工人聚到工会办公室；再说同一小楼在1923年与镇压罢工的历史联系，按报载身份叙述，不补人物心理。场景约两分钟即止。随后解释1949《共同纲领》已经起临时宪法作用、全国人大召开前的过渡安排，以及1954制定宪法并不是此前五年没有规则。用草案讨论与全国人大通过的区别收住，不报长串人数、册数、会议日期。[F4、F5] | 一部根本法所处理的是国家基本制度、权力与公民地位，不只是工作通知；人们参与讨论和有权机关最终通过有不同职责。接着必须看：这些根本事项到底写在哪里，而不是再找一位工人证明“群众重视”。 |
| 7—13分钟｜打开现行文本，看清“根本”管什么 | 明确从1954历史切换到2018修正的现行宪法。序言说明国家的根本任务、指导思想与发展方向；总纲说明国家性质、根本制度、党的领导和权力归属；权利义务章、国家机构章分别安排人的基本地位与机关，末章确认国家象征。以实际内容形成宪法概念，区别权力与权利；只定位少数条文，不逐项背目录。不在这里增讲1908或1982修宪史。[F1] | “根本”不是排斥劳动、治安等具体问题的重要性，而是规定它们共同遵循的根本安排。文本既写“人民”，又写“国家机构”，下一步解释两者如何联系。 |
| 13—22分钟｜从能表达选择到持续负责 | 原样使用教师认可的豆选641字，历史背景已在段内交代。豆子、碗、秘密投票的过程承担真实参与条件的说明，不把当前课堂演成投票活动。接回宪法第二、三条：人民行使国家权力的机关、依法参与的其他途径；人大对人民负责受人民监督，有关机关由人大产生并对其负责受其监督；最低限度解释民主集中制，不说各级各类机关都由全民直接选出。现行选举法只支撑样段所用代写、无记名与计票核对，不扩展换届操作。[F1、F3、F6] | “人民主权”不仅是归属宣告，还需要组织形式、参与途径和持续的责任关系。这为民主制度化、法律化建立内容，也留下必须认真解决的问题：机关合法产生以后，它的每项行为是否都合法？ |
| 22—35分钟｜孙志刚案：既查如何执行，也查规定的权限 | 连续讲完整关键经过，约7分钟，见下方专门编排；用约4分钟分清实际执行与规范制定两层追问，回到宪法第五、三十七条及当时2000年《立法法》；余下约2分钟含理解检查A与教师讲评。案件只在这里完整出现，不在下节重讲。刑事追责、审查建议、国务院修改行政法规分别交代，不以死亡结果代替权限论证。[F1、F7—F11] | “按一份规定办”还不足以完成合法性说明；既要查行为是否符合规则，也要查规则本身的权限和上位法依据。由此解释最高法律效力，不让它只成为书面定义。接着把参与、依法履职与人的保障连成原则，而不是再开一场法制史讲座。 |
| 35—41分钟｜把经历过的认识归纳为原则 | 不为五项原则再找五个故事。回到已讲内容：第一条和序言说明党的领导；第二、三条说明人民主权、组织分工、负责监督；第五条说明社会主义法治；第三十三、三十七条说明尊重保障人权。解释这些要求共同作用于国家活动，党的领导与在宪法法律范围内活动不能分开读。用“民主的制度化、法律化”作为理解宪法本质的入口，同时说明国家性质、意志和利益的根本确立，不能只读成机关组织图。教材还有民主集中制等内容，本讲五项重点不冒称穷尽。[F1及既有教材核查] | 学生能把原则名称放回具体国家活动，不是听完案件只记住悲剧。权力需要履职能力，也需要法定权限、权利保障与监督；这些要求并不相互取消。根本安排既须稳定，又会面对调整的需要，接第六十四条。 |
| 41—45分钟｜能改，但不是随手改 | 读第六十四条两种提议主体、修宪与普通议案的不同多数要求，强调分母为全体代表；不作算票题、不重建一致同意模型。简要解释稳定与依法调整，收回“内容、效力、程序”三方面。最后用一个真正进入下节的问题收束：宪法已有最高效力，也确认权利，为何具体请求仍要查普通法律？[F1] | 可以修改不等于一般机关能用普通规定绕过宪法。上节完成根本地位与权力约束；下节不重新开始宪法定义，而是接到具体权利的制度实现。 |

### 上节深讲中心：孙志刚案怎样避免再被写成梗概

**保留的事件链：**2003年3月到广州工作不久的年轻人晚上出门，未随身携带身份证、暂住证未办；朋友送证仍未能接出；后经收容站、救治站，朋友得知死讯及最初死因说法；新闻调查报道的鉴定结论与该说法不同，工作、住所、证件与登记材料出现矛盾；4月25日报道引起关注，5月三名法学博士提出审查建议；6月一审报道交代致死经过及刑事责任；6月20日国务院公布新办法，8月1日施行并废止旧办法。

**组织决定：**前段以人的实际遭遇连续展开，后段以问题推动规范解释；这次按主要时间顺序讲，不先讲六月判决再无路标倒回五月。死因和致死经过分别按新闻调查、一审报道身份使用，**本轮没有取得原判决书、全部公安笔录、鉴定书或审查建议书**。不加入家属对白、血腥尺寸和未经核实的心理。

**必须讲出的知识：**“法律”在此是全国人大及其常委会制定的规范类型，不与国务院行政法规混作同一层级。2000年《立法法》第八、九条的法律保留与授权限制是当时的法源，不能套2023年后条号；宪法的最高效力及对自由的保障提出上位约束。学者提出抵触问题，与有权机关正式认定和依法处理不是同一行为。本课只建立区分，完整备案审查留第八讲。

**不能偷换的认识：**有工作、有住处、有身份证帮助揭示事实与登记的矛盾，但不是一个人应当获得人身权保护的资格门槛；即使没有这些条件，也不能任意施加伤害。三博士建议不等于已作违宪裁决，更不是一封信单独自动废止旧规。新办法第十一条不得限制受助人员离站，是具体规范变化，不是对所有执行效果的保证。

**理解检查A（含在22—35分钟内）：**“追究致死责任以后，为什么仍会有人要求审查收容遣送办法？”给约45秒留理由，教师用约75秒讲评。合格解释应有：追究具体人的责任没有回答该措施最初是否符合收容条件，更没有替法规自身的制定权限及上位法依据作判断；两层问题需各有证据，不能因事件惨痛直接宣布全部规范违宪。无需要求学生已掌握完整审查程序。

## 四、下节45分钟：一项根本权利怎样得到依法处理

| 时间 | 这一步实际怎样讲 | 学生应多理解什么，为什么接下一步 |
|---|---|---|
| 0—6分钟｜从权力约束转到受损者的请求 | 用一分钟回收上节，不重讲孙案。明确设定：县公安局以本机关名义实施违法行政拘留、侵犯某市民自由，相关事实作为本教学设例给定；恢复自由后，他提出赔偿请求。读宪法第四十一条第三款，说明这是法定条件下的权利，不是先获得工作人员同情才成立。随后提出仍未回答的实际问题：该查哪种赔偿情形、找哪个义务机关、请求如何提出？[F1、F2] | 宪法已经提供根本依据，不等于所有办理规则都已写完。这不是孙志刚案的续集，也不暗示现实案件一律已获确认违法。接着真正展示普通法律增加的内容。 |
| 6—13分钟｜法律给谁、给什么职责 | 国家赔偿法第一条连接宪法和立法目的；第三条第一项与第七条第一款集中说明行政职权、违法拘留及赔偿义务机关；第二条及时履行义务随例说明。第九条仅一句交代请求途径。以换承办人员后义务仍然存在，解释法定义务与私人善意的不同；追偿只用一句阻断“机关赔就个人当然没责任”，不教金额、期限或流程分支。[F2] | 普通立法不是把权利口号再念一遍，而是建立可适用的责任关系。知道“找谁”还不够，请求人要能把事情讲明白，进入下一处真实困难。 |
| 13—24分钟｜说得清却写不出，程序怎样回应 | 仍是同一个设例市民，现在明确增加书写申请书确有困难、但能口头说明的条件。先承认办理要取得具体请求、事实根据和理由。用约1分钟《韩非子》“郑人买履”的寓言，保留忘记尺码、回去取、集市散去及“何不试之以足”的行动关系；随即回到第十二条，比较代书、口头申请记入笔录怎样保留必要信息。说明不是法条要求必须亲筆，而是不能把一种熟悉的记录方式误作唯一途径。包含90秒对读和检查B。[F2、F12] | 改变信息记录方式，不等于取消核实；允许替代方式来自法律，不是执法者可凭寓言自行不守程序。也不因采用口头申请就预先确定全部赔偿结果。学生由一个实际办法看懂“权利具体化”，再抬头辨它与宪法的关系。 |
| 24—30分钟｜具体法律是在实现还是在创造宪法效力 | 从刚读的第十二条回到第四十一条与第五条：法律要选择可行办法，宪法并未逐字预写代书、笔录，但普通立法也不能以自己负责操作为由任意取消根本要求。“根据宪法”是制定依据说明，不自动证明每条都合宪；没有写这几个字也不免除宪法约束。以第六十四条的具体比例说明宪法不总是抽象，普通法也会有原则。[F1、F2] | 学生能同时承认立法的真实选择空间和上位约束，不落入“普通法只是抄写”或“普通法想怎么写都行”。规则已经安排好之后，下一步要有人实际去做。 |
| 30—40分钟｜1994年法律公布之后，机关还有哪些工作 | 转入国家赔偿法正式施行前的真实准备：1994年通过、1995年1月1日施行；读1994年12月22日国办通知中的具体任务，说明受理赔偿需要机构、人员、培训和配套。重点研究文中真实的“束缚手脚”顾虑及同时反对滥执法、不执法的要求。以文件如何回应实际履职问题展开，不长念公文，不另造某位申请人当年跑部门的新闻事件。[F13] | 法律通过不会自动配置人员、改变办事习惯或完成赔偿。约束违法行权不等于否定依法履职；应当履职时也不能以害怕责任为由一概不作为。正面说明“实施”需要怎样的工作，最后才能区分条文、工作和结果。 |
| 40—45分钟｜三层认识回收，预告第二讲 | 回到假设请求人：规范确认权利、法律组织办法、机关依法处理与履行并不自动相等。短引《孟子·离娄上》“徒善不足以为政，徒法不能以自行”，交代古代仁政论述的语境，用来凝练刚才看到的关系，不当作现代国家赔偿法的依据。赔偿落实有意义，也不把过去侵害变合法或让损失从未发生；可用一句“赔偿不是人生的撤销键”帮助感知，不再堆多组比方。完成检查C和讲评，预告第二讲如何沿不同历史问题理解宪法形成与变化。[F1、F2、F14] | 回答整讲的关系而非报一遍故事名单：宪法的根本安排约束国家活动，具体法律组织实现办法，但权利保障仍需履职和纠错。这节学到的不是“凡事都引用宪法就办完”。 |

### 下节关键段的展开与两项检查

**第十二条段不是十二分钟程序课。**计划的11分钟分配为：同一申请人的困难与办理所需信息约2分钟；寓言约1分钟；法条对读1.5分钟；比较两种法定记录办法及判断依据约3.5分钟；检查B及讲评约2分钟；回接宪法—普通法关系约1分钟。此分配是教学预算，不是文本字数或现场测量。

**检查B：**“改为口头申请以后，哪些东西变了，哪些没有变？”合格回答：变的是申请意思形成书面记录的方式；没有取消具体请求、事实和理由的说明及后续核查，实体赔偿结论仍要依法律判断。法律允许这样办理，不是工作人员法外施恩；不能把所有事项都推成可口头办。

**检查C（末段5分钟内）：**给一个明示假设——机关有国家赔偿法培训材料，但一项依法应处理的请求一直无人实际办理。请用一句或两句区分“已有规范”“完成准备”“实际履职”。合格回答：制度依据与培训不证明请求已经依法处理；应检查具体义务由谁履行、哪一步尚未落实，而不是只凭发生问题就否定全部法律效力。约45秒思考、75秒讲评，剩余时间用于全讲收束和预告。

## 五、材料为什么这样取舍

### 保留并指定用途

**长辛店**承担一个短历史入口：国家根本规则进入普通人的生活。不是证明工人多认真，不再同时接李凤鸣、莫谈国事、118万意见和十六册材料组成长开场。

**豆选**保留教师认可641字，放在权力归属与参与制度之间。它与下节代书可以有一次简短回扣：不会书写不等于没有需要表达的选择或请求，但两项权利和法律依据各不相同，不能称同一套制度。

**孙志刚**是上节唯一长案件。集中讲清其真实冲突和两层规范问题，避免把它压成三分钟事故—改革梗概；不让下节正在发展的赔偿请求突然暂停去听另一个完整案件。

**1994实施通知**是下节主要真实制度背景，不是无趣公文的替补。它记录了真实履职顾虑，并提出组织和培训任务，足以从“法律规定了”推进到“必须怎样工作”。

**郑人买履**和**孟子原句**分别承担一种小而明确的任务：前者帮助辨别需要完成的任务与所采用的办法，后者为已经讲清的“善意、规则、执行”关系作文化回收。寓言不当史实，古典政治思想不当现行规范。两者都不另开思想史专题。

### 本次不进入默认课堂，但资料不删除

- 李凤鸣暂不与长辛店串成另一长段：当前7分钟历史入口承担的不是完整全民讨论史。此前修通的两例衔接可作未来素材，但不是本讲必走路线。
- 《钦定宪法大纲》、1982章次变化：有比较价值，但这次不把文本结构导读变成宪法史课；原大纲将系统发展留第二讲。
- 孟子与齐宣王、商鞅完整传记、缇萦上书：各有思想价值，但把它们都纳入会增加新人物、新时代和古今法律解释负担，打断正在发展的课堂问题。不是否定引经据典，而是不以多典故替代深讲。
- 沈阳法院报告未通过：不恢复教师已否定的选材；也不因出处可得而强留。
- “118万多条意见、十六册”：本轮检索出现统计对象口径不同的线索，尚未取得足以裁断的原统计。本讲并不依赖这些数字，故不选用，不用一条转引悄悄修正另一条。

## 六、S1—S2实际研究如何校准方案

### 初案的资料需求，而非故事清单

先从已认可知识形成需求：①必须解释根本安排，而不是单讲宪法庄严；②权力归属需要组织和参与办法才能理解；③最高效力要能区别行为依据与规范依据；④一项赔偿请求要显示权利、法定义务和可行办法；⑤规则存在与实际保障之间缺什么工作。初案尚未预定所有素材，不以原12个标题、原典名单作为不可改骨架。

### 三轮相互修正

**第一轮：知识与课程边界。**关键词围绕“根本法/最高效力/国家机关/人民主权/法律保留/赔偿请求/法律具体化/实施”，核现行宪法、国家赔偿法，回看已认可全课与第一讲范围。明确国家赔偿保留，但条文细节只服务理解，不讲栏目、期限和追偿程序。并把“宪法产生效力”和“具体制度如何运作”区分。

**第二轮：材料是否真的完成这些任务。**定向回核1954原报数字化文字、豆选馆方介绍、孙案同期调查与一审报道、2000立法法、2003国务院令；原典回读《韩非子》《孟子》相关段落。研究确认孙案的当事人经历、媒体调查、司法认定、学者建议、国务院调整是不同层次，不能压成单一因果。因此给它上节13分钟，并让下节保持一个申请人，不在中途再铺长案件；先讲行为/权限的区别，再归纳原则。

**第三轮：用实施原件和教学反证检查初案。**此前1994通知常受PDF读取限制，本轮取得深圳市政府1995年公报转发的**国办发〔1994〕106号全文**。真实原文同时包含“束缚手脚”担忧、机构人员培训、滥执法和不执法，不必由模型编一个极端反方。教学研究方面，对照CMU目标对齐建议、Harp与Maslich2005讲授实验公开摘要，以及Tislar与Steelman2021有不同结果的研究摘要：有趣细节与学习关系受任务、材料和处理影响，不能从“无关细节可能干扰”推出一律删掉故事。这里把材料的解释作用、时长和可能误解纳入检查，不声称本班效果已证实。[T1—T3]

- 总Skill仍为v0.3，不在这轮再改版。law-professor中的概念、案例经过、历史和理由深化，落实到根本法与法律具体化的正面说明、孙案完整过程、1994通知的实际工作，而不是只作核错清单。
