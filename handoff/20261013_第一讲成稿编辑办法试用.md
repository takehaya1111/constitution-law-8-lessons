## 实际怎样执行

1. **内容检查。**主笔完整读输入稿；另以不继承本轮历史的独立上下文，只给审读者正文、授课对象与必要任务，不提供作者自评。审读者全文读403行，确认四处独立思考题均有实际讲评，主要故事时间与人物关系清楚；仅提出民主集中制名称与含义连接较少的问题。
2. **补足必要解释。**主笔回看已有教材原图，印刷105—106页/PDF物理120—121页，结合认可纲的后讲接口，补一小段民主选举、讨论决定、分工执行及监督的解释。只以人大处理国家事务作为理解入口，没有改成完整原则专题。
3. **口述编辑。**补释后，另用不继承历史的上下文只读当时完整正文，不读内容编辑意见或作者分析，检查指代、信息先后及实际说法。得到10组建议，主笔逐项取舍，统一改入现稿。原有正确答案、故事经过、专业限定、正常长句和有用回顾保留。
4. **核原意。**最后的核查者完整读当前401行与14处差异，对照认可纲及必要教材、法条和访谈内容，核主体、条件、事实身份及结论强度。该环节读取了来源和仓库入口，其中带有既往修订概述，所以不称盲审；没有用作者效果评价作依据。未发现改动引入的实质错误。

上述均为文字编辑。没有真人朗读、音频听审或学生模拟；不是同条件随机对照，不能仅据此证明新办法优于现行Skill或已经普遍有效。

## 本轮代表性改动

| 问题 | 实际处理 |
|---|---|
| 民主集中制出现名称，最低含义交代较少 | 按教材补民主选举、讨论、法定决定、分工和监督的联系，继续将具体制度交后讲 |
| 用上下班区分工作人员与公民 | 改为同一个人在不同法律关系中的身份，保留个人权利，不暗示只在下班后有权利 |
| “两句话都写得具体” | 直接说明比较的是宪法中的三分之二以上与假设普通法律中的过半数 |
| 杨之光段“母亲”与“钱包进手绢”可能听混 | 明确杨澄的母亲，改为妇女用手绢裹钱；仍标本人回忆、艺术构思及不同人物 |
| 先问“其他部门”，后讲法制部门职责 | 先交代法制部门负责内部接收审查，再讲找到其他部门怎么办；对外义务机关不变 |
| 甲题干“拘留及损害由同一机关作出”搭配不清 | 说明县公安局作出的行政拘留违法并造成损害，原讲评保留 |
| 两部法律交替讲，却只说“第五条” | 明确宪法第五条，并讲清立法机关权限与法律内容两项判断 |
| 上节修宪前提前插入具体措施权限 | 合并掉此处提前提示，该知识仍在下节现场情形及两种误解处完整说明 |

没有将所有建议照单全收：关于独立违法确认程序的提醒，未移到设例最开头，以免尚未进入程序时又先添一个陌生说法；改在申请途径段说明本例事实已知与现实程序要求的区别。它仍是原有边界，没有新增办理步骤。
