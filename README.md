# 宪法学八次课 · 课程内容仓库

本仓库保存《宪法学》的课程大纲、分讲知识纲、教材与法源、教学素材、口播稿、课件、师生材料及本课程执行记录。课程面向公安专业一年级，八次课、每次上下两节各45分钟，共16学时。课程知识内容和已认可分工保持。

**通用备课Skill独立维护于[classroom-oral-skills](https://github.com/takehaya1111/classroom-oral-skills)，本仓不维护第二套技能正文。**固定方法版本及课程输入接口见[方法入口](方法入口.md)。
