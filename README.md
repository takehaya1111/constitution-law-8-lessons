## 如何判断完成程度

八份课件均已存在，共116页；这表示文件齐全，**不表示八讲加工深度一致或已验证教学效果**。前七讲以内容转化和第一轮课件为主，第八讲另有实际学生材料、案例分发卡、讲评答案和逐页备注。下一轮的重点是教学内容与可用材料，而不是扩大文件数量。

仓库设为私有。访问者需要具备仓库读取权限；如果某个工具不能读PDF、图片或发布附件，应说明实际可读范围，不能将检索结果、文件列表当成已经读完原件。
