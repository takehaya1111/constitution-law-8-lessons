## 已确定的生产全流程

**课程总纲与分纲 → 口播Skill形成完整稿 → PPT Skill编制唯一正式PPT设计纲 → 制作、检查与交付PPT。**

口播负责完整讲述及必要教学意图，不预先抢做逐页设计纲；PPT端直接读实际采用的完整分纲、完整口播和材料，在自己的策划环节决定屏幕表达。阶段授权、当前作品与认可状态见[CURRENT_STATE](CURRENT_STATE.md)，不得由流程存在自动启动尚未委托的生产。

口播与PPT方法分别在独立技能仓维护，地址和本课核定版本统一见[方法入口](方法入口.md)。本仓不维护第二套Skill正文，也不静默安装或升级教师本机技能。
