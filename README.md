## 如何判断完成程度

初始八份课件共116页；第一讲现新增22页试做版，原13页版保留。按第一讲试做版和第2—8讲既有版计算，当前八讲可审阅课件合计125页。**文件齐全不表示各讲加工深度一致或已验证教学效果。**第一讲与第八讲已有更完整的材料和答案配套，第2—7讲尚未按本轮意见批量重写。

仓库设为私有。访问者需要具备仓库读取权限；如果某个工具不能读PDF、图片或发布附件，应说明实际可读范围，不能将检索结果、文件列表当成已经读完原件。
