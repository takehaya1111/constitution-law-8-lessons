## 四、承重论断的性质与使用边界

| 论断 | 性质 | 依据与限度 |
|---|---|---|
| 宪法是国家根本法，具有最高法律效力 | 法条原文与学理解释 | 序言、第5条；教材18—20页。教学定义不冒充逐字法条。 |
| 根本内容包括国家制度、任务、权利和权力组织 | 学理概括与我国例证 | 教材18页、宪法序言及有关章节；不意味普通法律不重要。 |
| 我国修改程序较普通法律更严格 | 法条对照与教学解释 | 第64条全国人大、全体代表、两种门槛；不泛化为所有国家。 |
| 宪法把人民当家作主制度化、法律化 | 教材学理概括及条文例证 | 教材20—21页、第2、3条；不扩为全部思想史，也不说教材仅有一个本质维度。 |
| 教材五项原则应有联系说明 | 教材分类与教师组织 | 五项名称保留；民主集中制放在组织活动层面说明，不取代其他原则。 |
| 人权原则在第一讲有规范意义 | 法条原文与教学联系 | 第33条第3款；第一讲解释与权力运行的联系，第五讲深化。 |
| 法律未写“根据宪法”仍受约束 | 法条要求与学理概括 | 序言、第5条、教材20页；具体法律内容是否合宪仍须另判。 |
| 立法具体化不赋予宪法首次效力 | 学理概括 | 宪法自身效力与国家赔偿对读；不能反向否定普通法律具体安排的重要性。 |
| 已给定违法行政拘留，可肯定赔偿权及义务机关 | 教学设例中的规范适用 | 国家赔偿法2、3、7条，题设明确行政职权及侵害；不推定金额、期限或程序结果。 |
| 笼统公益理由不足以证明具体授权 | 教学设例与推理 | 第5、33条和原则/具体规则的区别；要求说明具体缺口，不直接判定必然违法。 |
| 法律效力与实际效果需要区分 | 最低必要学理说明 | 用于理解最高效力与权利保障，不另建法理学单元。 |

## 五、对原材料的保留、恢复与压缩

1. **恢复并展开旧第17页线索。**宪法41条3款、国家赔偿法第1条的对应关系在教材印刷20页也可核到；本轮再读第2、3、7条，使学生看到具体情形和义务主体。并非仅补一句“根据宪法”。
2. **保留第13、18、22页的知识功能。**根本内容、本质和概念重新组织为实际讲解，并回教材和现行文本核对，不直接复制原句或版式。
3. **不直接沿用旧第17、72页的处理结论。**最高效力先讲“不得抵触”，有权机关如何纠正由相应制度处理；不把一般“违宪无效”扩成人人有权宣告普遍失效。复杂域外案件不进入本轮课堂。
4. **不采用1954年史料作为第一讲例证。**教材相关页提到起草委员会，不足以单独证明完整制定程序；本讲用第64条完成必要对照。第二讲如采用这部分，须分别核起草机构与审议通过机关，本轮只登记接口。
5. **删去旧课程的过重展开。**词源、分类目录、渊源细目和复杂规范结构不占本讲核心时间。旧设计里的未核案件、对学生实际表现的既有评价及旧考核安排不移入。
