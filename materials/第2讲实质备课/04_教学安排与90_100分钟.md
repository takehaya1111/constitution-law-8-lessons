# 第二讲教学安排与用时

## 本讲要形成的认识

公安专业一年级，两个学时。第一讲主要说明根本规则是什么、怎样起作用；第二讲转向它们怎样形成、怎样改变。完成本讲，希望学生能根据实际文字说明一项变化及其保留的安排，区分完整宪法文本、部分修正和普通法律制定，并用第64条及一组真实文件说明修宪主体与程序。

全景包括近代宪法起源、中国近代与根据地探索、新中国宪法和五次修正。重点不平均铺开所有年份，而是三组有实际原文的比较：1975—1982年的检察职权与人身自由，1982—1988年土地条款，2018年监察机关配套与修宪文件。没有把前两部分全推到课后，也没有把第二讲改成刑事诉讼或土地法课程。

## 90分钟核心

下列时间均为净教学时间，课间另计。每个学时有43分钟编排内容及2分钟机动；机动可分散用于指读、回答追问和回看，不必等到最后才用。讲稿中的教师口头反馈属于讲述时间，表中的活动另计后已包括在段落预算中。

| 时段 | 讲稿位置 | 内容与实际活动 |
|---|---|---|
| 0—3分钟 | 一 | 从现行题注打开“仍称1982年宪法”的疑问；标记日期约30秒 |
| 3—12分钟 | 二 | 近代背景和英美法不同问题；回看全景1分钟，回应约30秒 |
| 12—22分钟 | 三 | 中国近代探索与1912年实际条文；题1阅读1分钟、作答1分30秒、回应30秒，再讲评 |
| 22—26分钟 | 四 | 根据地探索和新中国四份完整文本，分清地域、时期与文件身份 |
| 26—30分钟 | 五 | 1982年的形成文件及同期说明；辨认报告与通过日期约1分钟 |
| 30—40分30秒 | 六 | 1975/1978示范后自读1982；题2阅读2分钟、作答1分30秒、回应30秒，再核对新增与承接 |
| 40分30秒—43分钟 | 七 | 第一学时回收，页边句约30秒 |
| 2分钟机动 | 第一学时各段之间 | 用于实际指读、追问和回看；第一学时合计45分钟 |
| 45—55分30秒 | 八 | 1982/1988土地对读；题3阅读2分钟、作答1分30秒、回应30秒，随后解释变化与保留 |
| 55分30秒—61分钟 | 九 | 五次修正各有内容位置；约1分钟对应年份和所选内容 |
| 61—68分钟 | 十 | 2018监察三处修改与普通法律的不同工作；原文阅读1分30秒 |
| 68—77分30秒 | 十一 | 第64条与2018真实文件链；题4回读1分钟、对应主体动作1分30秒、回应30秒 |
| 77分30秒—85分钟 | 十二 | 题5辨认完整文本、部分修正、普通法律；写作2分钟、同桌检查1分钟、回应30秒 |
| 85—88分钟 | 十三 | 回答开场疑问并接第三讲；出口句约30秒 |
| 2分钟机动 | 第二学时各段之间 | 用于实际反馈及回看；第二学时合计45分钟 |

时间行中的累计时点是一种可执行安排，不要求老师机械卡秒。第一学时如提前使用机动，后续时点顺延但总量仍为45分钟。不能既使用机动，又把表末的2分钟作为额外教学再次加算。

题1、2、3的作用不完全相同：题1在已解释的条文上练习识别权力根据与具体分工；题2从已示范的1975/1978转向学生自读1982；题3先找旧新改动，再由讲评说明所有权与使用权。没有将同例练习包装为学生已经独立掌握。题4辨认真实文书主体，题5回到本讲整体的版本关系。

## 100分钟条件性扩展

只有每学时50分钟时才执行，不暗加到90分钟中：

- **第一学时E1，5分钟：**第六部分后、第七部分收束前，依据英国1689年法案的译意和文件形式说明，辨析“不成文是否意味着没有任何书面文件”。阅读1分钟、同桌解释1分钟、回应30秒，其余为教师引导、反馈和转场。第一学时为43＋5＋2＝50分钟。
- **第二学时E2，5分钟：**第十二部分后、第十三部分收束前，对读1982年既有权利条款与2004年新增人权原则。阅读1分钟、独立写理由1分钟、回应30秒，其余为教师反馈和切换。第二学时同为50分钟。

扩展用已有材料深化一个区别，不另引新的复杂史例。英国当代全部宪法规则、基本权利完整理论和监察现行程序均不在这10分钟中追加。

## 容量核算与真实未决

当前核心口述为8566个汉字，其中第一学时4576、第二学时3990。统计只取讲稿“讲述”段落，排除教师备查、活动说明、标题和扩展；参考答案中的完整备查不要求再全部读一遍。核心学生阅读、书写、同桌交流和回应共24分钟，13段切换另按每段10秒估计，已占用段落预算。

以每分钟150汉字作自设核算条件，第一学时约42.17分钟，第二学时约41.1分钟；以140汉字核算，则约44.35和43.0分钟。后者会使用部分机动，但尚在45分钟内。数字不是教师实测语速，汉字数也未完整代表指图、数字念法、停顿和临时追问；只能检查明显超量，不能证明按时完成或学生理解。

新稿写成后，已将第六部分的1982新增项放到题2自读之后，将第八部分“删什么、增什么、保留什么”的答案性解释放到题3之后。这样增加的是学生实际对读的位置，原有完整解释仍在讲评中；没有让屏幕隐藏答案而教师事先全部念出。

本轮没有真人试读、计时课堂或学生表现记录。实际使用若持续超时，先压缩已明确结论的重复复述和全景中的口头重复名目，保住主要原文阅读、史料身份和反馈；不能靠加快朗读或删除关键条件维护纸面用时。统计细目见[用时核算](用时核算.json)。

## 相邻课程边界

第一讲的1949—1954六分钟导入不再重演；第二讲仅必要承接。第三、四讲继续解释现行国家性质、形式和基本制度；第六讲深入具体权利；第七讲说明现行机关职权；第八讲展开实施监督。本轮只登记接口，不改其正文或考核安排。
