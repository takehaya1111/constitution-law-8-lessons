## 访问受阻但仍有可用核查途径的材料

- 1988年全国人大常委会公报第3号：[公开影印链接](https://upload.wikimedia.org/wikipedia/commons/7/74/中华人民共和国全国人民代表大会常务委员会公报1988年第3号.pdf)。网页工具取得PDF77—79的文字提取，分别为修正案及公告、中央建议、常委会草案；本地下载403，原图未成功展示。因此此处没有放一份假称已经取得的PDF。形成材料采用已读文字与明确的身份说明；正式修正案另有上表官方文字交叉核查。
- 中国人大若干旧网页无法直接打开；检索服务能够返回部分正文。相应使用范围已在研究说明逐条限定。没有把访问错误当成正文不存在，也没有用页面摘要冒称原刊图像。
- 1949、1954原文复用仓库第一讲叙事候选版已经保存的官方网页副本，本次在线回访超时。只定向回读本轮承接的条文；没有再次复制同一批文件。

文本均以UTF-8保存。这里不归档学术文章全文，不将研究者假设、媒体标题或模型生成文字伪装成历史原件。
