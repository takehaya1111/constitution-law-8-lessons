# 第一讲整合：知识依据、覆盖与去重

2026年9月29日。本文件为整合制作前的定向核查与内容选择依据。执行基准为 `e300d6e70d7aa8ad611790f93d68379c528f68fb`；依据[统一执行方案](../../../handoff/20260929_第一讲整合与思辨表达_统一执行方案.md)及[原Pro审阅M1—M5](../../../research/20260929_第1讲承重单元_Pro审阅与整讲整合任务.md)。本文件没有把研究判断称为学习效果，也不自行增加课时或考核安排。

## 一、整合应当改变什么

第一讲要让学生把国家根本安排、国家权力的组织运行和公民权利放到同一个解释中。赔偿关系是观察这些安排如何进入具体法律的一处窗口。整讲不应让学生只留下“违法拘留找哪个机关赔”的印象。

22页内容版保留了明确的知识职责；26页叙事版增加了制度形成、共同约束与实施工作的解释，但前14分钟历史铺垫和后半堂赔偿沿革占用较多时间。26版五项原则集中到第73—77分钟，容易成为案例后的名称回收。新主版本应提前解释国家权力的归属、产生、负责和监督，把第33条的人权要求纳入这条关系，随后用赔偿例子观察它的一项具体落实。

短单元新增的主要理由——立法本身也是国家权力的行使、规范约束与具体安排回答不同问题——可以分别进入整讲的相应位置。原23分钟单元可以拆分，不能把它完整追加在旧90分钟后面。

## 二、第一讲的完整知识职责

| 必须讲清的内容 | 本讲需要形成的认识 | 主要依据及整合处理 |
|---|---|---|
| 宪法的概念与根本内容 | “根本”指安排国家生活的根本问题和制度前提，不能只改说“最重要”，也不是全部部门法细则的总和 | 教材18—20页；现行序言、第1—3条及章节结构。用实际内容组织概念，再给能展开的教学概括 |
| 序言与根本任务 | 宪法既确认国家性质和制度，也规定国家发展的根本任务；任务的实现须放在宪法组织的制度和规范中理解 | 序言关于根本任务的原句与末段须分别出现，不能用“规定了根本任务”替代具体任务内容 |
| 最高法律效力 | 宪法组织和约束国家权力，立法也须受到约束；普通法律不能自行排除共同根本规范 | 教材19—20页、序言末段、第5条。保留26版短反事实，接上现行规范依据；不是仅由“内容重要”逻辑推出最高效力 |
| 修改程序特殊性 | 根本规则保持稳定，同时保留依法调整的途径；我国第64条两种表决要求不同 | 只作同一机关、同一“全体代表”基数的比较。完整修宪过程留第二讲 |
| 宪法本质的必要解释 | 人民当家作主需要机关、产生方式、负责和监督关系，并获得法律确认 | 教材20—21页、第2、3条。从民主制度化、法律化切入；教师备注保留教材还讨论政治力量对比关系，主讲不扩思想史 |
| 基本原则的制度联系 | 领导地位、权力归属、组织方式、依法运行、人权要求、监督责任共同作用于国家活动 | 第1、2、3、5、33条；教材92—104页所核部分。原则不是五个孤立标签，也不画成自动产生结果的单向链 |
| 宪法与普通法律 | 最高效力解决“受到什么约束”，具体化说明“制度增加了什么安排”；法律的制度选择仍受宪法约束 | 第41条第3款及国家赔偿法第1、2、3、7、9条；教材20、219、319、323—325页 |
| 有限判断与必要缺口 | 事实足够时作出有依据的判断；事实不足时指出具体缺口。抽象目的不自动证明具体权限 | 赔偿设例保留行政职权、违法性及侵害事实；另有笼统公共利益情境，区分未知授权与已经证明违法 |

### 序言材料的一处实际补足

22版学生材料A包含根本任务原句，26版材料二只有序言末段及文本地图。26版虽然多次说“国家根本任务”，学生手上却没有该任务的具体表述。新学生材料应恢复：

> 国家的根本任务是，沿着中国特色社会主义道路，集中力量进行社会主义现代化建设。

这是现行宪法原文。教学上可解释：根本任务为国家建设确定方向，但不是凭目标就可以任意选择手段的授权。第5条的共同遵守要求和人权条款同样适用于国家活动。此处不用展开全部国家目标，也不把序言当作没有规范意义的历史介绍。

## 三、原则为什么能够讲在一起

### 1. 由同一个国家活动追问不同关系

第1条规定我国国家性质、根本制度及党的领导的宪法地位。第2条规定国家权力的归属和行使机关。第3条继而说明人大怎样产生、向谁负责，其他有关国家机关与人大形成什么关系。这几条使“谁拥有国家权力”“权力怎样得到组织”有了不同但相连的答案。

只讲权力的产生仍不够。一个机关依法产生，并不使它的每一次行为天然正确。第5条要求国家机关和各政党等遵守宪法法律，也排除超越宪法法律的特权；第33条要求国家尊重和保障人权；第3条又规定负责和监督关系。这些规定共同说明，国家权力有制度上的来源，也有运行中的责任。

教材94页明确把党的领导与领导立法、保证执法、支持司法、带头守法及在宪法法律范围内活动联系起来。整合时可以用这一关系充实旧版“党的领导”卡片，避免它只是版面上的单独名称。上述连接来自教材和法条，不由某位博主的表达方式提供法律依据。

### 2. 民主集中制的最低充分说明

教材五项原则的组织是：坚持中国共产党的领导、人民主权、社会主义法治、尊重和保障人权、权力监督与制约。民主集中制有第3条第1款的明确地位，应结合国家机构组织活动讲授，不替换五项中的任何一项。

本讲至少把第3条中的“民主选举产生”“对人民负责、受人民监督”与国家机构的统一组织联系起来。不能只解释为下级服从上级，也不能只画机关名称而删去产生、负责和监督这些关系。第3条还规定中央与地方国家机构职权划分；可以在教师备注保留全文定位，具体展开留国家机构课。

第2条第3款还规定人民依法通过各种途径和形式管理国家、经济文化和社会事务。因此，介绍人大这一国家权力机关，不应说人民只能经由人大参与全部公共事务。第一讲不必追加所有民主形式，留下这一准确边界即可。

### 3. 人权在原则段落出现，赔偿再使其中一种保障具体可见

第33条不是为了给后面的赔偿例子贴标签。它先确立国家活动应当尊重和保障人的权利。赔偿随后回答：当题设中的国家侵权损害已经发生，权利保障怎样表现为法定请求、责任主体和处理安排。

“尊重”与“保障”在这里可用不任意侵害和积极作制度安排作入门说明。国家赔偿只是救济的一部分，不能代表全部人权或全部基本权利。第五讲再系统讨论基本权利原理。本讲不增加以权利分类为目标的识记任务。

## 四、赔偿单元怎样服务整讲

### 1. 各条实际增加的信息

| 条文 | 在本讲中的工作 | 不能据此跳到什么结论 |
|---|---|---|
| 宪法第41条第3款 | 在根本法层面确认受国家侵权损失者依照法律规定取得赔偿的权利 | 不是任何不满都成立，也未单独给出全部数额和程序 |
| 国家赔偿法第1条 | 明示宪法依据，将保障赔偿权与促进依法行使职权并列为目的 | 起首措辞不是全法合宪或实际效果良好的证明 |
| 第2条第1款 | 给出依本法取得赔偿的职权行为、法定侵权情形和损害条件 | 不能把旧1994年“违法行使职权”措辞冒充现行原文 |
| 第3条起句及第1项 | 在行政职权领域列出违法拘留等具体赔偿情形 | 不因工作人员属于公安机关，就略去正在行使何种职权 |
| 第7条第1款 | 为本设例确定承担赔偿义务的行政机关 | 对外的机关义务不等于工作人员当然免责；其他责任仅留教师备查 |
| 第9条第2款 | 表明提出请求的途径也须由法律安排 | 不只截取前半句使学生误认任何情况下均须先单独向义务机关请求 |

学生主要辨认第3、7条，第2条提供范围支持。第9条完整相关款句放附页，教师简短点明其制度用途，不再把路线记忆变成本讲重点。完整款句为：

> 赔偿请求人要求赔偿，应当先向赔偿义务机关提出，也可以在申请行政复议或者提起行政诉讼时一并提出。

### 2. 已有效力与需要具体安排可以同时成立

教材319页说明宪法具有直接法律效力，219页说明国家赔偿请求权的宪法依据。国家赔偿法进一步确定适用情形、义务机关及请求途径，并不是让宪法第一次生效。另一方面，第41条并未把所有现实办理问题预先写尽。法律通过具体制度使有关权利要求可以进入办理，并应当符合宪法。

这里要保留立法形成空间。具体化不等于从一个宪法句子机械演算出唯一制度；国家赔偿法的一切细节也不是第41条的重复抄写。教材324页把依据宪法分别联系到立法授权、程序、原则精神和规范内容。教学中只须使学生看到法律在这些约束下形成具体办法，无须加入整套学术争论。

### 3. M1、M2与M3一起落地

同例定位题只保留短版，让学生找到第3条的情形和第7条的义务机关。随后的另一项任务应要求解释规范关系，例如回应“宪法没有写由谁办理，所以权利有没有约束力也应等普通法律选择”的异议。答案要指出它混淆了已有规范约束与制度安排的具体程度，并举法律增加的一项安排。

学生题设保留“以本机关名义”“行使行政职权”“违法拘留”“人身自由受侵害”及相关事实已给定。共同机关、委托、撤销、法定不赔等排除条件移入教师备注，作为本设例适用第7条第1款的设计范围，不让学生先记一串本课不教的制度。事实已给定也不是要求现实请求人普遍先取得另一个确认违法决定；本讲不教授该程序。

关系题的依据应出现在学生可读材料中，不只在教师讲稿中。答对刚示范过的定位题可以说明能跟随练习，不能据此宣布学生已经独立理解宪法与立法关系。

## 五、沿革与背景的取舍

1. **1949—1954只保留有解释任务的短对照。**26版第2—4页可以帮助学生理解已有过渡性制度继续展开为根本制度。若采用，保留《共同纲领》第13条与1954年宪法第21条的联系；1953年机构成立、草案公布和讨论的完整年代链留第二讲。删掉短对照会失去制度形成背景，删掉完整时间线则主要减少历史信息，不妨碍本讲现行规范解释。
2. **照片只承担历史定位。**旧新华社照片为1954年9月15日代表进入怀仁堂，不能称9月20日表决现场，不补人物心理或对白。照片本身不能证明宪法最高效力。
3. **赔偿沿革不再重讲一套时间线。**26版第14—15页关于1982、1994、1995的节点可移教师备查。现行条文已能承担本讲主任务。若需要解释法律公布后仍有组织实施工作，可在条件性扩展中用1994年国办通知的一小段说明机构和人员安排；它是当时要求，不证明要求已经实现，更不是今天的处理依据。
4. **保留历史纠错的结果，不把纠错过程念给学生。**1949—1954不是没有规则的空白期，1994以前也不是没有赔偿规定。教材219页把2012年修法与范围、程序、精神损害等改革放在相邻叙述中；既有核查已区分主要相关修改在2010年。本轮不重做修法史，主讲使用现行条文，教师仍可回查[上一轮说明](../../第1讲承重单元应用验证/02_知识对象深化与依据.md)。

- 张翔：[《宪法与部门法的三重关系》机构转载](https://cserl.chinalaw.org.cn/portal/article/index/id/385/cid/25.html)。本次重读概念区分、立法具体化及形成空间有关段落，并核页末书目身份。原刊为《中国法律评论》2019年第1期26—33页；转载明确来自原刊公众号且脚注从略。未取得原刊版式PDF，也未递归审查全部脚注。
- 王锴：[《立法具体化是宪法实施的方式吗》明德公法网转载](https://calaw.ruc.edu.cn/xfyj/xfss/79d78648add94687b9093ba68622c6f9.htm)。本次实际打开正文，读取摘要、开头对实施/监督/保障的区别及页末来源。《法学论坛》2024年第1期可确认。沿用此前对立法具体化的有界研究，不声称本次重读全篇全部注释。

两种学理提示共同用于限制概括范围：立法形成具体制度需要选择，不等于把宪法解释权完全交给下位法；承认这一空间也不意味着可以排除宪法约束。不同论文如何界定全部宪法实施，留教师备查。课堂无需以学者名称或学说数量增加负担。
