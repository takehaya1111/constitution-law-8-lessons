# 第一讲的教学安排与两种学时用法

授课对象为公安专业一年级。课程仍为八讲、16学时。本讲目标是让学生解释根本法的内容与地位，把国家权力的组织、依法运行和权利保障联系起来，并借国家赔偿法说明宪法要求与具体制度的关系。课堂练习用于理解和反馈，不设置新的考核比例。

## 一、90分钟核心

31个核心显示页组成一条完整讲述。第1—16页为第一学时，第17—31页为第二学时，分别45分钟；课间另计。下表不是纯讲解时间，已经包含对应的阅读、作答、回应、教师反馈和转场。

| 净教学时间 | 课件页 | 内容与活动 |
|---|---|---|
| 0—6分钟 | 1—2 | 照片导入与一项历史制度对照：国家已有规则，为何仍制定宪法 |
| 6—19分钟 | 3—6 | 序言根本任务、根本内容、概念与最高效力；实际读序言和第5条 |
| 19—25分45秒 | 7—8 | 第2、3条的产生、负责、监督关系；民主制度化、法律化的必要解释 |
| 25分45秒—34分钟 | 9—11 | 党的领导与依法活动、人权保障、五项原则共同作用于国家活动 |
| 34—38分45秒 | 12—13 | 任务1先解释两处条文的联系，再讲评 |
| 38分45秒—45分钟 | 14—16 | 第64条必要对照、任务2及第一学时收束 |
| 45—50分45秒 | 17—18 | 第41条与国家赔偿法第1条的权利、目的和依据对读 |
| 50分45秒—60分钟 | 19—21 | 第3、7条增加的条件与义务机关；第9条简短说明制度入口 |
| 60—64分15秒 | 22—23 | 任务3事实与条文定位、有限判断及讲评 |
| 64分15秒—75分30秒 | 24—26 | 集中解释既有效力与制度形成；任务4关系说明及反馈 |
| 75分30秒—83分30秒 | 27—29 | 起首句判断、权限资料缺口，两种不同的迁移任务 |
| 83分30秒—90分钟 | 30—31 | 制度联系与实际实施，任务7及整讲回收 |

材料应在本讲开始前发到学生手中。A提供历史节录、现行序言与目录，B提供根本制度、权力组织及原则条文，C提供第64条，D提供赔偿条文；附页保留第9条完整第二款。学生无需预先知道国家赔偿法。实际题目在学生册，逐题理由和边界在教师册。

第12/13、15/16、22/23、25/26、28/29页分别是设问与讲评两个真实显示状态。第27页先停留思考，随后作口头反馈，画面不预填答案。第31页先写出口解释，教师再口头收束。不能为赶时间把问答页连点过去。

## 二、100分钟条件性用法

只有学校确定每学时50分钟时，才在上述核心中分别插入以下内容：

- **第一学时增加5分钟：**核心第16页后，使用附页32—33的E1。用第64条修正“宪法只有抽象原则”的说法，再解释具体程度不决定效力地位。独立判断1分钟、同桌解释1分钟、学生回应约30秒，其余为引导、讲评和切换。然后课间，回到第17页。
- **第二学时增加5分钟：**核心第30页后，使用附页34—35的E2。围绕规则明确但请求未依法处理的假设，指出需要查明的实施环节，区分规范效力与实际办理。独立思考1分钟、同桌交流1分钟、回应约30秒，其余为引导、讲评和切换。随后回到第31页收束。

这样形成50＋50分钟；不把两项扩展再塞进原90分钟。第36页仅为来源查读，不另安排课堂逐条朗读。课件采用单一主版本，扩展放在末尾，按以上页码插入；不是另交一套平行风格。

## 三、容量核算与实际限度

核心讲述及教师口头讲评共8973个汉字，第一学时4909、第二学时4064。只统计内容源中“讲述”部分，排除操作提示、来源、题目附页及教师备查；不是把字数当作质量指标。独立阅读、写作、交流和学生回应约22分43秒，另按每页5秒预留切换，共约2分35秒。教师讲评已在讲述文字内，不漏算也不重复加算。

以每分钟150个汉字作自设估算，第一学时约42.8分钟，第二学时约42.3分钟，剩余用于自然停顿、指读和机动反馈。以较慢的140字估算，则约45.1和44.3分钟，第一学时可能稍超预算。它提醒教师前半堂解释较密，而不是要求加速朗读。以上速度均非本班或教师实测，页内时段可以相邻调整，总学时须实际计时校准。

一次桌面核算发现第12、15页的题目引导时间被作答挤占，已增加对应页预算并从讲解余量调整；第31页增加30秒供完整回收。另一处内容审查发现第21页提前完成第24页的论证，已将完整理由集中到第24页，腾出的时间增加给第25页关系解释。容量调整先处理实际重复和活动需要，没有删去法条条件来换时间。

本轮没有真人朗读、学生试用或教室投影；上述只能支持材料编排，不能证明学习效果。真实使用若超时，优先减少同例讲评中已明确的复述，保留根本概念、原则联系和任务4的理由反馈；记录超时位置后再改稿，不以临时赶读维持纸面90分钟。
