## 一、八讲16节：具体教什么，讲到哪一层

表中的“精讲”指解释知识及其关系，“概述”指建立必要背景，“定位”指能在文本中找到并说明它回答什么问题。每行的45分钟是固定课时边界，**不是新成稿容量验证**。

| 讲次、课节 | 具体知识与关系 | 本节达到的深度及与上下节的分工 |
|---|---|---|
| **1 宪法总论·上节（45分钟）** | 从《共同纲领》已经存在的过渡安排、全国人大与国家制度进一步展开、1954年宪法确认根本安排的真实过程进入，再转读现行序言、总纲与四章结构，解释国家根本任务、制度、公民地位和权力组织。由具体内容形成概念，以第5条建立包括普通立法在内的最高效力。将第2、3条的权力归属、组织、负责与监督，和第1、5、33条的领导、依法活动、人权要求连起来，归纳五项基本原则；本质以“民主制度化、法律化”作必要入口。 | 重点论证机关需要履职能力、专业判断与及时行动，同时法定地位不保证每项行为正确；依法判断、责任和有权限的监督须相接，不能止于“两边都重要”。第64条保留约4分钟的特别多数与普通议案门槛、全体代表分母及稳定/依法调整理由；全体一致长模型与60%独立演算转备查。历史不是此前无规则，也不能只以稳定解释根本性。不完整讲机关职权、权利理论或修宪流程。 |
| **1 宪法总论·下节（45分钟）** | 沿同一赔偿请求读宪法第41条第三款及国家赔偿法第1条，第2条随例交代范围，第3条第一项与第7条第一款集中解释情形和赔偿义务机关。第12条进入重点论证：保留核实所需信息，同时以代书、口头申请及记入笔录改变取得信息的方式；说明书面记录的用途、可行替代和对请求机会的影响。1994通知沿宪法赔偿依据及已有行政赔偿基础—专法系统安排—施行前的机构、人员和配套工作，形成真实过程。 | 深化宪法有效、法律具体化、机关依法履职与实际保障的关系，具体安排不是赋予宪法效力。第12条只分析必要信息与办理形式，不教栏目、期限或管辖，不冒称正式合宪审查模型或证明全法合宪。第9条短说明请求途径，全文在资料；第16条主要备查，默认仅阻断机关赔偿即个人当然免责的误读。保留一处第12条后的解释机会，合并任务链与重复讲评；公益授权长设例退出默认，第八讲再讲完整实施监督。 |
| **2 宪法的发展·上节（45分钟）** | 从现行题注进入，概述英、美、法不同问题与中国近代、根据地两条探索；定位1949及四份完整文本。以1980—1982已核形成报告连接国家任务、权利与机关安排，再把1975—1978—1982三版自由保障及检察、公安分工作唯一深读中心。 | 三版都有保护文字；1978恢复须保留，再看批准、决定、执行与禁令的变化。重点解释不同职责有机会实质检验先前理由，而不是环节越多越好；分工与配合、制约同讲。背景不变五个小专题，1949/1954只回顾第一讲。报告理由、规范变化和实际效果分清；住宅移位及历史/现行条号一次交代。权利和现行机关职权留第5—7讲。 |
| **2 宪法的发展·下节（45分钟）** | 1988土地作深读主例，区分城市土地所有权安排保留、使用权流转改变与“依照法律”的配套任务。五次修正保留全景，1999/2004仅短说明已有基础与新增一般要求。监察改文与2018修宪过程合成连续第二单元：先约6分钟说明新增机关牵动人大、国务院及机构章关系，再接第64条的两种提议主体和关键法定行为；第124条与2018初版监察法说明普通立法配套。 | 土地例重点解释改变利用方式不等于改变全部所有制、制度基础保留不等于运行办法永不调整；不以拍卖独自解释修宪。第二单元不分别再开监察、日程、三文件三轮任务，准确日期和文书身份留资料，普通立法不能自行改写宪法。第一讲门槛直接调用，不恢复模型；不讲土地交易细目、现行监察措施或完整人权理论。结尾用已讲三类材料归纳全面修改、部分修改与普通立法。 |
| **3 国家性质与国家形式·上节（45分钟）** | 第1条分别定位国家性质与根本制度；第2条分出权力归属、人民行使国家权力的机关与依法参与事务。用第3条民主选举、负责和监督的基本关系，解释人民代表大会制度作为政体怎样承接人民当家作主。 | 首次系统区分国体与政体：前者回答国家性质，后者回答国家权力如何组织和行使；人民代表大会制度不是一个机关名称。第1讲原则仅调用，第2讲历史仅作来处；不重复机构职权清单，也不将各级人大一律说成全民直接选举。 |
| **3 国家性质与国家形式·下节（45分钟）** | 第3条末款、第4、30条连接中央与地方、行政区域和民族自治地方；“单一制”是对安排的学理概括，国家结构形式不是行政区划表。第31条说明设立特别行政区及其制度的宪法依据；第141—143条定位国家标志。 | 主讲国家权力的地域组织与国家统一，区别一般行政区域、民族自治地方和特别行政区。民族区域自治在此只解释地域结构中的位置与不可分离性，第4讲说明制度性质，第7讲辨自治机关。特别行政区基本法的制度细目、国家标志专门法律及行政区划实时数字不展开。 |
| **4 国家基本制度·上节（45分钟）** | 第6条区分社会主义公有制的基础、所有制结构和分配制度；联系第7、11、15条认识国有经济、非公有制经济和社会主义市场经济各回答什么问题。再调用第1—3条及序言，画清国家性质、政治制度与国家机关的联系。 | 经济制度精讲，政治总体安排作承接；不把第6条各款混成一个名称，也不以企业比例或政策举例取代宪法原句。“经济、政治、文化、社会、生态”是教学整理的板块，不是宪法规定的五个同层级制度。国体/政体定义不再重讲。 |
| **4 国家基本制度·下节（45分钟）** | 保留“人民—选举—代表—人大”作唯一重点政治制度样例，把第2、3、34条连起来。其余制度须有最低限度的知识说明：序言说明多党合作和政治协商制度长期存在发展、政协是有广泛代表性的统一战线组织；第4条说明民族自治地方在统一国家内行使自治；第111条说明居民/村民委员会为基层群众性自治组织，办理居住地区公共事务，其与基层政权的关系依法规定。第22、21、26条示范文化、医疗卫生、环境保护国家任务，其余第19—26条形成回查图。 | 精讲选举与人大联系，不展开选举法程序；第34条的个人选举权条件留第6讲。其他政治安排讲到性质与文本位置，不只列名词；民族自治的具体自治权、基层自治运行程序不增加为第二套深讲，不改选自治专题。文化、社会、生态定位国家任务，不能直接推出每项个人请求权。 |
| **5 基本权利的一般原理·上节（45分钟）** | 并读第33条，区分人权、宪法基本权利与普通法律权利的层次，说明公民资格、平等、人权保障和权利义务并存分别表达什么；联系第32条辨在华外国人合法权益保护与公民条款的文字差异。 | 首次系统讲概念与主体，承接第1讲人权原则。知道规范层次、保护对象和具体化方式不能混为一谈；不从“人权入宪”直接推出每项具体请求。国籍细则、法人主体及私人间效力的复杂理论只列需要另外论证的问题，不给未经核实的定论。 |
| **5 基本权利的一般原理·下节（45分钟）** | 基本权利对国家活动的约束与保障要求；精读第51条，联系具体权利条款和普通法律，建立“主体—受保护利益—限制依据、目的与事实—程序缺口”的判断。材料充分时形成有理由、有条件的有限判断，材料不足时指出具体缺口，不能全部练习都只问还缺什么资料。私人之间的争议先查普通法律，宪法价值如何影响解释另需学理说明。 | 主讲权利效力、保障与限制的分析起点。法律保留、比例原则用于提示需追问的问题，不能伪作第51条逐字规定的完整公式；公安设例解释限制理由及依据怎样影响判断，不凭一句条文终局断案。第6讲新增具体权利，第8讲新增规范审查路径。 |
| **6 具体基本权利与基本义务·上节（45分钟）** | 调用第5讲框架，精读第33条第二款平等权，辨比较对象、差别与正当理由；以第37、39条精读人身自由与住宅保护，第38、40条定位人格尊严与通信保护。第34—36条建立选举、政治自由、宗教信仰自由的条文框架。 | 主讲平等与人身自由，其他类型讲清受保护利益及条文位置。合理差别不能由“有差别”或“目的正当”一句话决定；进入住宅等执法设例仍须查法律授权、事实和程序。个人选举权与第4讲选举制度分工，权利现行含义与第2讲历史对照分工。 |
| **6 具体基本权利与基本义务·下节（45分钟）** | 定位第13、41—50条的财产、监督请求、社会经济、文化教育及特定群体保护，抽读第41、42、46条。独立讲基本义务概念和第52—56条：统一与民族团结、遵守宪法法律及所列要求、祖国安全荣誉利益、依法服兵役、依法纳税。以第33条末款及第42、46条的权利义务双重表述、第49条婚姻家庭中的义务补清范围。 | 第52—56条是义务的主要集中线索，不是宪法义务穷尽清单。权利图用于全貌，不逐条深讲；基本义务有独立解释，不能仅在课末列五个词。权利与义务并存不意味着每项权利都有对应义务，或权利只能作为先履行义务的奖励。履行条件、处罚查具体法律；第41条申诉、控告与赔偿不等同第8讲备案审查。 |
| **7 国家机构·上节（45分钟）** | 调用第2、3条，建立国家机构及民主集中制的组织关系；精读第57、62、67条，比较全国人大的最高国家权力机关地位、常委会的常设机关地位，以及修宪、立法、重大事项、监督等代表性职权。连接人大与国务院的产生、负责和监督关系。 | 第3讲的政体与第4讲选举关系成为前提，这里新增具体机关及职权归属。常委会不是全国人大的“执行机构”；机关地位不消除宪法约束。修宪仅辨全国人大职权，不重讲第2讲过程；不同中央机关不得一律用同一句“产生—负责”关系替代各自条文。 |
| **7 国家机构·下节（45分钟）** | 重点辨人大与监察、审判、检察机关的关系及各自宪法职能；沿行政关系链说明地方人大与政府的性质及职能。国家主席结合第79—81条说明由全国人大选举、依宪法履行公布法律等代表性职权；中央军委依第93、94条说明领导全国武装力量及主席负责关系，不只出现在图上。依第112、115条说明民族自治地方自治机关是相应人大和政府，兼有同级地方国家机关职权与依法自治权；居委/村委的基层群众自治不混作自治地方国家机关。第140条联系两院与公安办理刑事案件的分工、配合、制约。 | 主讲机关配置与关系；产生、负责、监督、领导分别用文字标清依据和方向，不用同一无标注箭头。组成、任期和完整职权长清单为查读。公安具体执法措施另查法律；监察机关的国家监察、检察机关的法律监督不等同宪法监督全部内容。自治机关辨主体和职权性质，不展开自治条例审批及财政等细目。第8讲再运用这些主体说明实施与纠正机制。 |
| **8 宪法实施与监督·上节（45分钟）** | 调用第1讲效力与法律具体化，用宪法第46条及教育法第1、9条说明实施不限于争议后纠错，还包括立法落实、机关依法履职以及社会主体遵守。解释解决现有规定如何理解，修改改变文本，监督关注贯彻与纠正；对读第62、64、67条及全国人大组织法第39条，区别全国人大、常委会、宪法和法律委员会的职权与工作职责，另辨主案法工委。 | 在已有教学设计与课件上校准；新增实施主体、路径和职责，不再完整重讲赔偿法或修宪流程。教育法展开已有宪法要求，不赋予宪法效力；一处条文落实不能证明所有教育实践充分保障。教师、学者或工作机构研究意见不直接称常委会正式解释。案例甲只引出规范问题，理由与结果在下节展开。 |
| **8 宪法实施与监督·下节（45分钟）** | 完整读2021年报告中地方性法规终身禁业事例的对象、理由、工作机关与“修改调整”结果；联系劳动权属于课堂分析。比较草案阶段的合宪性问题与公布后的备案审查：对象、时点、标准和法定职权有交叉，备案审查还涉及上位法、权限等问题。用地方性法规示范建议、审查、沟通与依法处理，再区分法规条款与具体行政决定。 | 深讲一则已核案例和一条有法定范围的示范路径，不概括为所有文件唯一程序。报告肯定公共安全目的并限定上位法条件，不能改写成全部限制违宪；提交建议不自动撤销个案决定，工作意见不等于正式撤销或违宪宣告。复议、诉讼的对象边界只作教师准确讲评依据，期限、管辖等不展开。收束八讲的规定、落实与保障关系。 |

## 二、同一知识再次出现时，新增了什么

| 内容线索 | 首次建立 | 重点展开或后续调用 |
|---|---|---|
| 根本法、最高效力、法律具体化 | 第1讲上节建立地位与约束，下节借赔偿解释宪法要求与制度选择。 | 第2讲用历史修改辨宪法层与普通立法层；第7讲用来辨机关地位与规范约束；第8讲新增实施职责、审查标准与纠正路径，不重讲全部赔偿关系。 |
| 修改、解释、实施 | 第1讲以程序特殊性入门；第2讲主讲文本变化与实际修宪身份。 | 第8讲回顾“解释理解现文、修改改变现文”，新增正式职权与实施作用；没有安排第1、第2、第8讲三次完整门槛论证。 |
| 人大制度 | 第1讲原则导入；第3讲首次系统讲政体。 | 第4讲新增人民、选举、代表与人大的联系；第6讲看个人选举权；第7讲新增具体机关及职权关系；第8讲只调用监督实施职责及相关工作主体。 |
