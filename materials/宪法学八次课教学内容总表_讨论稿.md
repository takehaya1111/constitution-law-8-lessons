## 一、八讲16节：具体教什么，讲到哪一层

表中的“精讲”指解释知识及其关系，“概述”指建立必要背景，“定位”指能在文本中找到并说明它回答什么问题。每行的45分钟是固定课时边界，**不是新成稿容量验证**。

| 讲次、课节 | 具体知识与关系 | 本节达到的深度及与上下节的分工 |
|---|---|---|
| **1 宪法总论·上节（45分钟）** | 从《共同纲领》的过渡安排与1954年宪法进入，认识为什么国家需要持续的根本规则；读序言以及总纲、权利义务、国家机构、国家标志四章的文本结构；认识宪法规范是应遵循的原则或具体规则，读序言中的国家根本任务与根本法地位，区分根本内容、最高效力和修改程序特殊性。结合第1—5、33条认识党的领导、人民权力归属、依法组织和行使权力、尊重保障人权及监督制约之间的联系；本质以“民主制度化、法律化”作必要入口。 | 精讲根本法概念及条文关系，最高效力在此首次建立：立法者及其他规范受宪法约束，同时仍需作具体选择。第64条只作特别门槛与普通法律门槛的必要对照，简述稳定与依法调整的两面理由；现稿的完整门槛模型、60%演算是否退出主线，见第三节待审项。不完整讲国家机构、权利理论或修宪流程。 |
| **1 宪法总论·下节（45分钟）** | 以宪法第41条第三款和国家赔偿法为窗口：宪法已经确认赔偿权并约束普通立法；专门法律增加法定情形、义务主体与办理安排。第1条显示制定依据和目的，第2条给范围，第3条与第7条分别说明本例情形和机关义务。由此分清“已有宪法效力—具体制度尚需形成—机关仍须依法办理—实际保障尚需检验”。 | 深化宪法与普通法律的关系，区别规范地位与文字具体程度：宪法也可以有具体规则，普通法律也可以有原则；法律细化不是赋予宪法效力，也不是免除宪法约束。第12条如何兼顾核实条件与申请困难，是一个精读候选，须Pro取舍；第9、16条拟只作附页或短对照。1994年实施通知可解释法律施行尚需组织工作，但不据此判断今天全部实效。金额、期限、管辖、追偿流程及完整监督机制不在本讲展开。 |
| **2 宪法的发展·上节（45分钟）** | 从现行题注分清1982年完整文本与后来的修正；用英、美、法不同处境概述近代宪法的权力组织、约束和权利保障问题。中国近代以1908与1912的权力依据及分工为代表，并给根据地探索独立位置。把1949、1954、1975、1978、1982放回全景；主讲1982年形成材料及1975—1978—1982的人身自由、检察与公安分工同题对照。 | 历史全景用于定位，具体原文用于说明保留与改变，同期报告用于解释当时提出的理由；三者不代替实施效果证据。1949/1954只回顾第一讲已讲的过渡与完整宪法，不重讲导入。精读1982形成与同题比较；不把“新增禁令”反推为旧法一概许可，也不因条文移位认定保障删除。权利制度和现行机关职权分别留第5—6、7讲。 |
| **2 宪法的发展·下节（45分钟）** | 用1988年土地条文说明所有权安排保留与使用权依法流转的新增；五次修正各有全景位置，主讲2018年监察机关新增与人大关系、国务院职权及国家机构专节的配套变化。结合第64条与2018年真实文件，辨政治建议、拟稿、法定提议、审议、通过和公布；最后比较全面修改形成完整文本、局部修正和依据宪法的普通立法。 | 新增的是变化对象、规范层次与文件身份，以及条文要求和实际过程的联系；第1讲最高效力及门槛理由只作必要回顾，不再演算门槛。土地物权、现行监察措施不扩讲；五次修正不逐条铺开，2004人权原则深化等为有条件候选。普通立法可配套，不能据此自行改写宪法；完整实施和监督机制留第8讲。 |
| **3 国家性质与国家形式·上节（45分钟）** | 第1条分别定位国家性质与根本制度；第2条分出权力归属、人民行使国家权力的机关与依法参与事务。用第3条民主选举、负责和监督的基本关系，解释人民代表大会制度作为政体怎样承接人民当家作主。 | 首次系统区分国体与政体：前者回答国家性质，后者回答国家权力如何组织和行使；人民代表大会制度不是一个机关名称。第1讲原则仅调用，第2讲历史仅作来处；不重复机构职权清单，也不将各级人大一律说成全民直接选举。 |
| **3 国家性质与国家形式·下节（45分钟）** | 第3条末款、第4、30条连接中央与地方、行政区域和民族自治地方；“单一制”是对安排的学理概括，国家结构形式不是行政区划表。第31条说明设立特别行政区及其制度的宪法依据；第141—143条定位国家标志。 | 主讲国家权力的地域组织与国家统一，区别一般行政区域、民族自治地方和特别行政区。民族区域自治在此只解释地域结构中的位置与不可分离性，第4讲说明制度性质，第7讲辨自治机关。特别行政区基本法的制度细目、国家标志专门法律及行政区划实时数字不展开。 |
| **4 国家基本制度·上节（45分钟）** | 第6条区分社会主义公有制的基础、所有制结构和分配制度；联系第7、11、15条认识国有经济、非公有制经济和社会主义市场经济各回答什么问题。再调用第1—3条及序言，画清国家性质、政治制度与国家机关的联系。 | 经济制度精讲，政治总体安排作承接；不把第6条各款混成一个名称，也不以企业比例或政策举例取代宪法原句。“经济、政治、文化、社会、生态”是教学整理的板块，不是宪法规定的五个同层级制度。国体/政体定义不再重讲。 |
| **4 国家基本制度·下节（45分钟）** | 沿既有设计选“人民—选举—代表—人大”作唯一重点政治制度样例，把第2、3、34条连起来。其余制度须有最低限度的知识说明：序言说明多党合作和政治协商制度长期存在发展、政协是有广泛代表性的统一战线组织；第4条说明民族自治地方在统一国家内行使自治；第111条说明居民/村民委员会为基层群众性自治组织，办理居住地区公共事务，其与基层政权的关系依法规定。第22、21、26条示范文化、医疗卫生、环境保护国家任务，其余第19—26条形成回查图。 | 精讲选举与人大联系，不展开选举法程序；第34条的个人选举权条件留第6讲。其他政治安排讲到性质与文本位置，不只列名词；民族自治的具体自治权、基层自治运行程序不增为第二套深讲。文化、社会、生态定位国家任务，不能直接推出每项个人请求权。若改为深讲自治，须Pro重定样例及相应退出项。 |
| **5 基本权利的一般原理·上节（45分钟）** | 并读第33条，区分人权、宪法基本权利与普通法律权利的层次，说明公民资格、平等、人权保障和权利义务并存分别表达什么；联系第32条辨在华外国人合法权益保护与公民条款的文字差异。 | 首次系统讲概念与主体，承接第1讲人权原则。知道规范层次、保护对象和具体化方式不能混为一谈；不从“人权入宪”直接推出每项具体请求。国籍细则、法人主体及私人间效力的复杂理论只列需要另外论证的问题，不给未经核实的定论。 |
| **5 基本权利的一般原理·下节（45分钟）** | 基本权利对国家活动的约束与保障要求；精读第51条，联系具体权利条款和普通法律，建立“主体—受保护利益—限制依据、目的与事实—程序缺口”的判断。私人之间的争议先查普通法律，宪法价值如何影响解释另需学理说明。 | 主讲权利效力、保障与限制的分析起点。法律保留、比例原则用于提示需追问的问题，不能伪作第51条逐字规定的完整公式；公安设例只练判断信息与依据，不凭一句条文终局断案。第6讲新增具体权利，第8讲新增规范审查路径。 |
| **6 具体基本权利与基本义务·上节（45分钟）** | 调用第5讲框架，精读第33条第二款平等权，辨比较对象、差别与正当理由；以第37、39条精读人身自由与住宅保护，第38、40条定位人格尊严与通信保护。第34—36条建立选举、政治自由、宗教信仰自由的条文框架。 | 主讲平等与人身自由，其他类型讲清受保护利益及条文位置。合理差别不能由“有差别”或“目的正当”一句话决定；进入住宅等执法设例仍须查法律授权、事实和程序。个人选举权与第4讲选举制度分工，权利现行含义与第2讲历史对照分工。 |
| **6 具体基本权利与基本义务·下节（45分钟）** | 定位第13、41—50条的财产、监督请求、社会经济、文化教育及特定群体保护，抽读第41、42、46条。独立讲基本义务概念和第52—56条：统一与民族团结、遵守宪法法律及所列要求、祖国安全荣誉利益、依法服兵役、依法纳税。合读第33条末款及第42、46条的权利义务双重表述。 | 权利图用于全貌，不逐条深讲；基本义务有独立解释，不能仅在课末列五个词。权利与义务并存不意味着每项权利都有对应义务，或权利只能作为先履行义务的奖励。履行条件、处罚查具体法律；第41条申诉、控告与赔偿不等同第8讲备案审查。 |
| **7 国家机构·上节（45分钟）** | 调用第2、3条，建立国家机构及民主集中制的组织关系；精读第57、62、67条，比较全国人大的最高国家权力机关地位、常委会的常设机关地位，以及修宪、立法、重大事项、监督等代表性职权。连接人大与国务院的产生、负责和监督关系。 | 第3讲的政体与第4讲选举关系成为前提，这里新增具体机关及职权归属。常委会不是全国人大的“执行机构”；机关地位不消除宪法约束。修宪仅辨全国人大职权，不重讲第2讲过程；不同中央机关不得一律用同一句“产生—负责”关系替代各自条文。 |
| **7 国家机构·下节（45分钟）** | 重点辨人大与监察、审判、检察机关的关系及各自宪法职能；沿行政关系链认识地方人大与政府。国家主席、中央军委在完整图中定位。依第112、115条说明民族自治地方自治机关是相应人大和政府，兼有同级地方国家机关职权与依法自治权；居委/村委的基层群众自治不混作自治地方国家机关。第140条联系两院与公安办理刑事案件的分工、配合、制约。 | 主讲机关配置与关系，组成、任期和完整职权长清单为查读。公安具体执法措施另查法律；监察机关的国家监察、检察机关的法律监督不等同宪法监督全部内容。自治机关在此只辨主体和职权性质，不展开自治条例审批及财政等细目。第8讲再运用这些主体说明实施与纠正机制。 |
| **8 宪法实施与监督·上节（45分钟）** | 调用第1讲效力与法律具体化，用宪法第46条及教育法第1、9条说明实施不限于争议后纠错，还包括立法落实、机关依法履职以及社会主体遵守。解释解决现有规定如何理解，修改改变文本，监督关注贯彻与纠正；对读第62、64、67条及全国人大组织法第39条，区别全国人大、常委会、宪法和法律委员会的职权与工作职责，另辨主案法工委。 | 在已有教学设计与课件上校准；新增实施主体、路径和职责，不再完整重讲赔偿法或修宪流程。教育法展开已有宪法要求，不赋予宪法效力；一处条文落实不能证明所有教育实践充分保障。教师、学者或工作机构研究意见不直接称常委会正式解释。案例甲只引出规范问题，理由与结果在下节展开。 |
| **8 宪法实施与监督·下节（45分钟）** | 完整读2021年报告中地方性法规终身禁业事例的对象、理由、工作机关与“修改调整”结果；联系劳动权属于课堂分析。比较草案阶段的合宪性问题与公布后的备案审查：对象、时点、标准和法定职权有交叉，备案审查还涉及上位法、权限等问题。用地方性法规示范建议、审查、沟通与依法处理，再区分法规条款与具体行政决定。 | 深讲一则已核案例和一条有法定范围的示范路径，不概括为所有文件唯一程序。报告肯定公共安全目的并限定上位法条件，不能改写成全部限制违宪；提交建议不自动撤销个案决定，工作意见不等于正式撤销或违宪宣告。复议、诉讼的对象边界只作教师准确讲评依据，期限、管辖等不展开。收束八讲的规定、落实与保障关系。 |

## 二、同一知识再次出现时，新增了什么

| 内容线索 | 首次建立 | 重点展开或后续调用 |
|---|---|---|
| 根本法、最高效力、法律具体化 | 第1讲上节建立地位与约束，下节借赔偿解释宪法要求与制度选择。 | 第2讲用历史修改辨宪法层与普通立法层；第7讲用来辨机关地位与规范约束；第8讲新增实施职责、审查标准与纠正路径，不重讲全部赔偿关系。 |
| 修改、解释、实施 | 第1讲以程序特殊性入门；第2讲主讲文本变化与实际修宪身份。 | 第8讲回顾“解释理解现文、修改改变现文”，新增正式职权与实施作用；没有安排第1、第2、第8讲三次完整门槛论证。 |
| 人大制度 | 第1讲原则导入；第3讲首次系统讲政体。 | 第4讲新增人民、选举、代表与人大的联系；第6讲看个人选举权；第7讲新增具体机关及职权关系；第8讲只调用监督实施职责及相关工作主体。 |
| 民族自治与基层自治 | 第3讲讲民族自治地方在统一国家地域结构中的位置。 | 第4讲说明民族区域自治与基层群众自治各是什么、在哪里；第7讲辨自治地方人大和政府及依法自治权。特别行政区另依第31条定位，不与这两种自治混为一类。 |
| 权利与国家任务 | 第1讲人权与权力关系入门；第4讲文化、社会、生态国家任务。 | 第5讲新增权利主体、效力和限制；第6讲新增具体权利与独立基本义务；第8讲调用受教育权与劳动权进行实施和审查分析，国家任务不自动变成具体请求权。 |
| 权力监督、国家监察、法律监督 | 第1讲监督制约为原则；第7讲辨机关及主要职能。 | 第8讲新增宪法监督与规范审查机制，不把国家监察或检察机关法律监督视为宪法监督的同义词。 |

必要回顾应直接调用已建立的认识，再展示本讲新增知识；不能仅把同样的完整解释换一则故事便称为递进。第三至八讲的故事、案例和课堂组织继续沿已有设计，本轮不为六讲另选整套故事或生产正文。

## 三、旧纲—实际差额—处理建议

| 原安排及位置 | 实际材料的差额 | 有依据的处理建议与待审状态 |
