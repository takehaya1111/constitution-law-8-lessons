# 《宪法学》课程教学大纲（内容稿）

> 2026年10月7日阶段A摘要校准，具体课次分配见[总表待审稿](宪法学八次课教学内容总表_讨论稿.md)。本文件承接已有课程定位和目标，不新增考核、学分或学校字段。Pro补足实质规划、教师确认后再整理正式大纲；同名DOCX仍为前一版导出件，未同步本次待审摘要，不作为当前阶段A提纲。

**课程名称：**宪法学。**授课对象：**公安专业一年级。**总学时：**16学时，分八次授课，每次上下两节各45分钟，课间另计。上述三项已由授课教师确认。本稿先确定课程定位、目标和八次课的教学内容；学分、考核比例、正式教材版本等须按学校的新课程方案核定，不能沿用原《法理与宪法学》32学时、2学分的混合课程信息。

## 一、课程定位

本课程以《中华人民共和国宪法》文本为核心，帮助学生理解宪法的根本法地位、现行宪法的形成、国家性质与形式、国家制度、公民基本权利和义务、国家机构，以及宪法实施与监督。公安职业情境用于练习辨认公权力的宪法位置、基本权利影响和需要继续查询的具体法律；课程知识主线仍是宪法学。

## 二、课程目标（草案）

完成16学时后，学生应能：

1. **读宪法文本。**在序言、总纲及有关章节中定位国家根本任务、基本原则、权利义务和国家机关条款，解释宪法作为国家根本法的地位。
2. **说明国家制度。**以条文为依据区分国家性质、政体、国家结构形式和主要制度，画出全国人大及其常委会与其他国家机关的基本关系。
3. **分析权利问题。**对简短情境先辨主体、可能涉及的基本权利或义务、尚需核实的限制依据与事实，不凭单一宪法条文直接裁断具体执法行为。
4. **辨认实施与监督路径。**区分规范性文件可能抵触宪法法律的问题与具体行为的问题，说明宪法实施、解释、监督、合宪性审查和备案审查的基本关系。

这些目标是新课程的拟定目标。旧大纲关于法理学、宪法学并列的总目标及旧考核方式不直接转入。

## 三、教学内容与学时分配

| 次序 | 主题 | 必讲内容与课堂达到的程度 | 学时 |
|---|---|---|---:|
| 第一次 | 宪法总论 | 从序言和总纲认识国家根本任务、基本原则、宪法文本结构、最高法律效力；能说明宪法与普通法律的关系。 | 2 |
| 第二次 | 宪法的发展 | 认识宪法产生的必要背景、中国宪法发展关键节点、1982年现行宪法及历次修改；能用一处修宪说明制度发展。 | 2 |
| 第三次 | 国家性质与国家形式 | 区分国体、政体、国家结构形式；认识中央与地方、行政区划、特别行政区和国家标志的宪法位置。 | 2 |
| 第四次 | 国家基本制度 | 重点理解经济与政治制度的宪法安排；从条文定位文化、社会、生态相关国家任务与制度，不把不同板块说成宪法规定的同一层级。 | 2 |
| 第五次 | 基本权利的一般原理 | 理解人权、基本权利及主体、效力、保障与限制；能按“主体—受保护利益—限制依据”提出问题。 | 2 |
| 第六次 | 具体基本权利与基本义务 | 精读平等权、人身自由，定位政治、宗教、社会经济、文化教育和监督等权利；独立讲授第52—56条基本义务及权利义务关系。 | 2 |
| 第七次 | 国家机构 | 重点理解全国人大及其常委会的宪法地位和职权，以及它们与行政、监察、审判、检察等机关的关系；其他机关按机构图定位。 | 2 |
| 第八次 | 宪法实施与监督 | 说明宪法规范如何进入立法和公权力行使，认识宪法解释、宪法监督、合宪性审查与备案审查的基本关系；区分规范审查与具体行为问题。 | 2 |
| **合计** |  |  | **16** |
