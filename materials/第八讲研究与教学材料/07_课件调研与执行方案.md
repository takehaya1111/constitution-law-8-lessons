# 第八讲课件：调研与执行方案

日期：2026年9月27日。范围：把已认可的两学时教学设计、学生材料和参考答案转为可编辑课件，附教师备注与预览。授课对象仍为公安专业一年级。

## 一、三轮准备分别解决什么

### 第一轮：核对已有材料与制作条件

前七讲已有七份课件，共92页。读取现有生成器与第7讲源数据，并查看封面、职责比较、机构图的实际渲染。采用原有16∶9画幅、深色封面、米白正文、暗红强调与微软雅黑。现有生成器提供要点、对照、引文、直线流程和练习等页型，但没有写入教师备注，直线流程也不能表达审查的条件与处理分支。

第八讲的Word材料和13项论断来源已经完成核对。此轮继续使用这些成果，重点研究投影呈现、分步提问和流程图，不重新扩展课程知识范围。

### 第二轮：查呈现依据与规范更新线索

查阅Mayer《Using multimedia for e-learning》的出版页摘要和通俗说明，采用突出关键材料、图文就近、删去无关装饰的设计思路。该文针对计算机多媒体学习，本课程将其用于版面取舍是一项教学设计判断，不能据此声称课件已经验证学习效果。[出版页](https://onlinelibrary.wiley.com/doi/10.1111/jcal.12197)

卡内基梅隆大学教学中心强调学习目标、活动和评价对应，并建议讲授中设置短任务和阶段小结。因此问题页与讲评页分开，课堂作答仍由已编学生材料承接。[教学原则](https://www.cmu.edu/teaching/principles/teaching.html)、[讲授组织](https://www.cmu.edu/teaching/designteach/teach/instructionalstrategies/lectures.html)

再次限定中国人大网检索“法规、司法解释审查工作程序”与2026年份，未获得正式公布文本。这不证明其绝对未出台；本课继续以已经核对的立法法与2023年备案审查决定画程序。官方案例网页的本轮HTTPS读取超时，已有公报扫描镜像、官方转引本地副本与逐字核对记录可复用。

### 第三轮：顺序和误读风险复核

独立复核提出：甲、乙、丙应有三个明确揭示点；第一学时先完成正面实施例和职责判断；历史案例与现行程序要分开；课件不能用满屏长文替代作答材料。生成流程复核另指出：需要补充备注、分支页型以及第八讲专用检查入口。

采用24页结构，其中22页用于讲授与活动，2页为资料索引；第一学时第1—10页，第二学时第11—22页。新增页主要用于问题与讲评分开、流程拆分，不增加案例数量或程序法知识范围。页数是本次编排选择，非教学研究规定的标准。

## 二、方案取舍

| 做法 | 适用性与取舍 |
|---|---|
| 直接把Word逐段搬到幻灯片 | 内容完整，但条文、提问和答案挤在一起，不利于分步判断。 |
| 保持原有样式，重排成课堂呈现，并加教师备注 | 采用。学生看到短引文、问题、关系图与讲评；教师能在备注中回查完整来源和边界。 |
| 增加新案例、视频及复杂动画 | 现阶段不采用。已有一例足以承担目标，额外材料会增加两学时容量和核验工作。 |

## 三、实质执行顺序

第三轮方案审阅后，把分步揭示细化为以下页目。第17—18页只作教师演示，学生只须辨认提交、启动、意见与处理之间的区别，不增加程序背诵任务；试讲超时优先压缩流程口述，保留案例和迁移作答。

| 页 | 教学目的 | 发卡、作答与信息揭示 |
|---:|---|---|
| 1 | 课题与核心问题 | 进入第八讲。 |
| 2 | 接回前七讲 | 说明从权利、国家机构到实施的问题。 |
| 3 | 主案提出问题 | 发甲卡，只读对象和限制内容，不出现理由与结果。 |
| 4 | 条文联系练习 | 读宪法46条与教育法1、9条，完成任务一A。 |
| 5 | 实施例讲评 | 揭示立法落实权利要求，宪法自身已有最高效力。 |
| 6 | 解释、修改、监督辨析 | 讲三种任务各在解决什么问题。 |
| 7 | 职责任务配对 | 对照学生材料二先作答，投影不填答案。 |
| 8 | 职责讲评 | 分别呈现人大、常委会和委员会的职权或工作。 |
| 9 | 实施的多种方式 | 依宪立法、机关履职、监督保障共同回应总问题。 |
| 10 | 第一学时收束 | 学生口头说明一次实施动作；主案理由与结果仍待揭示。 |
| 11 | 审查理由原文 | 发乙卡，先读报告并判断哪种概括有依据。 |
| 12 | 理由讲评 | 保留公共安全目的、上位法条件、调整意见；劳动权联系标明课堂分析。 |
| 13 | 处理结果原文 | 发丙卡，首次展示“已修改调整”，补齐四格卡。 |
| 14 | 四格卡讲评 | 按对象、理由、主体动作、结果整理已有材料。 |
| 15 | 草案阶段条文 | 读立法法58条，先判断问题处理的时点。 |
| 16 | 两类审查的联系 | 讲评审查标准、范围与时点，不把二者等同。 |
| 17 | 提出建议与启动审查 | 展示范围、初审和启动条件，补充主动审查入口。 |
| 18 | 意见与实际纠正 | 展示制定机关纠正、未纠正后的进一步处理和反馈。 |
| 19 | 虚构迁移练习 | 给出甲法规、乙决定及提交建议的事实，先作答。 |
| 20 | 迁移讲评 | 两个对象各有制度线索，建议不自动撤销决定。 |
| 21 | 课末三句 | 口头回答或课后完成，暂不显示填词答案。 |
| 22 | 全课总结 | 给出三句参考，把第八讲接回八讲体系。 |
| 23 | 条文来源附页 | 课后查读，不增加课堂作答任务。 |
| 24 | 案例与教学材料附页 | 标明公报原页、官方转引与配套材料。 |

## 四、呈现与内容规则

1. 第一学时使用案例甲及条文材料，第二学时才发乙、丙；投影中的标题、摘要和备注调用提示不能提前暴露结果。
2. 法律、报告直接引用保留原意与必要条件；摘录删去完整句子时使用“节录”并记录位置。教学概括明确标示。
3. 全国人大及其常委会的职权、宪法和法律委员会的工作职责、法工委报告意见与制定机关实际调整各有主体。
4. 2021案例只画报告明确记载的事实；现行程序另以地方性法规为示范，保留初审条件、机关范围、修改纠正及进一步处理。
5. 投影主体文字以22—28磅为主，来源页脚适度缩小；拥挤时先拆段和缩短讲评，详细说明写入备注。
6. 流程箭头表达法定条件或教学顺序，不用装饰箭头暗示宪法效力取决于普通立法，也不把审查建议画成必然撤销。
7. 引文全文、答题空格保留在学生材料；投影只呈现当前环节需要的内容。阶段总结保留具体答案，不能全课只有“尚需核查”。

## 五、交付与验收

成品放在本目录“第八讲课件”：可编辑PPT、PDF预览、逐页讲授说明、源数据与生成脚本、检查记录。原七讲文件和原始材料保持原状。

完成条件：24页顺序与教学设计相符；每页有来源和备注；三项任务均有对应讲评；案例揭示顺序正确；直接引文可回查；文件结构通过，实际渲染无文字截断、碰撞、箭头穿字或越界。课堂容量和学习效果仍须教师审阅、试讲判断。
