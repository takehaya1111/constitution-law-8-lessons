# 第八讲课件内容与呈现核对

本轮在《07_课件调研与执行方案》形成并经顺序审阅后开展，使用已完成的规范与案例研究。重点是把文字材料转成投影时，避免因为删字、分栏或画箭头改变原有含义。

## 一、实际核对及形成的决定

| 课件位置 | 核对问题 | 依据与处理 |
|---|---|---|
| 第3、11、13页 | 甲、乙、丙能否分别揭示而保持原意？ | 对读原公报印刷第246页、学生卡和源数据；三段完整保留，实际结果只在第13页出现。 |
| 第4—5页 | 三处条文是否变成“法律赋予宪法效力”？ | 对读宪法46条、教育法1及9条。并列显示原文，讲评确认宪法已有最高效力；不用效力产生的箭头。 |
| 第7—8页 | 配对题是否提前泄题，是否混淆委员会与常委会？ | 先空表、后讲评；对读宪法62、64、67条和组织法39条，明确最终职权与相关工作职责。 |
| 第12、14页 | 压缩理由会不会丢掉上位法条件？ | 第12页把理由拆成肯定部分、分析条件、调整意见，须连读；第14页保留“法律、行政法规未设从业限制的领域”的条件。 |
| 第12—14页 | 劳动权联系、沟通主体和结果有无扩大？ | 劳动权联系标作课堂分析；“经沟通”不补写执行者；结果只说已修改调整。 |
| 第15—16页 | 备案审查是否被讲成所有合宪性审查？ | 立法法58条另作独立原文入口，先辨认公布前时点，再说明两类审查有联系但不等同。 |
| 第17页 | 审查建议是否被画成自动启动？ | 核立法法110、111、115条和2023年决定6、9项，显示初审、法定问题情形、移送分支，注明图只展示一支。 |
| 第18页 | 意见是否被画成直接撤销？ | 核立法法112—113条和决定13—15项，分别画制定机关纠正和未按要求纠正后的进一步处理；具体权限、计划中止等放入教师备注。 |
| 第19—20页 | 个案决定是否因审查建议自动改变？ | 题面和讲评分开；甲为地方性法规，乙为具体行政决定，提交建议与撤销决定是不同法律行为。 |
| 第21—24页 | 总结和附页是否增加课堂负担？ | 先由学生补三句，再显示参考答案；两页来源只作查读，不新增考点。 |

## 二、文字与文件检查的范围

- 投影中的7段直接引文，与已保存的法律或报告文本逐段匹配；统一空白与字符宽度后全部相符。
- 每页均写入讲授备注、出处或材料对应位置；来源附页的可用网址也写入备注。
- 用课件包内正文检查揭示顺序：报告“已对相关规定作出修改调整”的原句首次出现在第13页。教师备注用于备课，不向学生提前展示。
- 机关、条件、程序和迁移题经过独立内容复核；代理意见仅用于找错，法律结论仍以原始规范和报告为依据。

## 三、呈现依据及适用限度

本轮查阅了Mayer论文出版页的摘要、通俗说明，以及大学教学中心的讲授建议。采用的具体做法是突出条文关键词、让说明贴近所指对象、分开作答与反馈、保留阶段小结。没有把多媒体研究的效果量套用到本课，也没有据此规定固定页数或声称学生效果已经验证。

- [Mayer，Using multimedia for e-learning](https://onlinelibrary.wiley.com/doi/10.1111/jcal.12197)：实际阅读摘要与通俗说明，未记为全文精读。
- [卡内基梅隆大学教学中心：教学原则](https://www.cmu.edu/teaching/principles/teaching.html)：目标、活动、评价对应及内容取舍部分。
- [卡内基梅隆大学教学中心：讲授组织](https://www.cmu.edu/teaching/designteach/teach/instructionalstrategies/lectures.html)：引导、过渡、小结、短任务部分；未据其注意力曲线规定课堂时长。

规范与案例的完整出处、阅读范围及未知事项继续使用《02_研究核对记录》。新工作程序正式文本的检索仍未得到确认，本课不把该研究制定安排当作已生效规范。
